The global service of Arknights: Endfield has two servers: Asia, whose server time is UTC+8, and Americas / Europe, whose server time is UTC-5. Progress is not shared between them; on one server it is shared across every platform under the same Gryphline Account. A version update closes both servers at the same moment for six hours: 06:00 to 12:00 UTC+8 on Asia is 17:00 to 23:00 UTC-5 on the day before on Americas / Europe. Timed content, such as a headhunting banner, opens and ends at the same clock time in each server's own server time, so it happens 13 hours later on Americas / Europe.

## The two servers

| Server | Server time | How a player lands on it |
| --- | --- | --- |
| Asia | UTC+8 | Chosen at login on PC, Android, iOS and Steam; GeForce NOW reaches both servers. On PlayStation 5, a PSN account registered in Hong Kong, for example |
| Americas / Europe | UTC-5 all year, July included | Chosen at login on PC, Android, iOS and Steam; GeForce NOW reaches both servers. On PlayStation 5, a PSN account registered in North America, for example |

- Account data is not shared between the two servers. Logging in to the other server does not bring a character's progress across.
- One Gryphline Account can hold more than one character; the data panel of the GRYPHLINK launcher switches between them.
- On PlayStation 5 the server follows the region of the PSN account; it cannot be chosen by hand.

Which platforms share progress, and how accounts are linked: [Platforms and requirements](/systems/platforms/).

## What server time means

A time marked "(server time)" is read on the clock of the server you play on: UTC+8 on Asia, UTC-5 on Americas / Europe. The same written time therefore happens 13 hours later on Americas / Europe. A time written with an offset, such as the release or a maintenance window, is one moment on both servers.

| What is written | Asia server | Americas / Europe server | In UTC |
| --- | --- | --- | --- |
| Release on all platforms, 2026-01-22 11:00 (UTC+8) | 2026-01-22 11:00 (UTC+8) | 2026-01-21 22:00 (UTC-5) | 2026-01-22 03:00 on both |
| The Hearth Fire Beckons the Starry Flow opens 2026-11-05 12:00 (server time) | 2026-11-05 12:00 (UTC+8) | 2026-11-05 12:00 (UTC-5) | 04:00 on Asia, 17:00 on Americas / Europe |
| Sanctuary of Ink update maintenance | 2026-10-15 06:00 to 12:00 (UTC+8) | 2026-10-14 17:00 to 23:00 (UTC-5) | 2026-10-14 22:00 to 2026-10-15 04:00 on both |

Content that runs until the next version's update maintenance ends when the maintenance begins: 06:00 UTC+8 on Asia, which is 17:00 UTC-5 the day before on Americas / Europe. Its last day therefore reads one day earlier on Americas / Europe.

## Update maintenance of every version

Times are UTC+8. Each window is the same six hours on the Americas / Europe server, 17:00 to 23:00 UTC-5 on the day before.

| Version | Update maintenance |
| --- | --- |
| [1.1 Old Deep Water Dies, by Rising Tide It is Denied](/versions/1-1/) | 2026-03-12 06:00 to 12:00 |
| [1.2 At the Wake of Spring](/versions/1-2/) | 2026-04-17 06:00 to 12:00 |
| [1.3 Sketches of Lost Heirlooms](/versions/1-3/) | 2026-06-05 06:00 to 12:00 |
| [1.4 Homecoming](/versions/1-4/) | 2026-07-16 06:00 to 12:00 |
| [1.5 Dreamscape of Wind and Snow](/versions/1-5/) | 2026-09-02 06:00 to 12:00 |
| [1.6 Sanctuary of Ink](/versions/1-6/) | 2026-10-15 06:00 to 12:00 |

[Version 1.0](/versions/1-0/) began with the release itself and had no update maintenance. Every update was mandatory: no login is possible during the window. A maintenance preview names the window two to five days before.

## Clock times that recur

| Time | Meaning |
| --- | --- |
| 04:00 (server time) | Daily refresh of daily rewards; many cycle missions and stage batches start or end at this time |
| 06:00 to 12:00 UTC+8 | Version update maintenance |
| 11:59 (server time) | End of a headhunting banner or of a phase within a version |
| 12:00 (server time) | Start of the next banner or phase, on the same day |
| Before version update and maintenance | Until the next version's update maintenance begins; the date follows from the maintenance preview |

《명일방주: 엔드필드》는 2026-01-22 11:00에 PC(GRYPHLINK 런처 및 Epic Games Store), PlayStation 5, iOS, Android로 정식 출시되었다. 2026-04-03에 GeForce NOW가 추가되었고, 2026-10-15의 1.6 버전 업데이트와 함께 Steam 버전이 출시되었다. 같은 서버에서 플레이하는 한 모든 플랫폼 간 진행도가 공유된다.

## 플랫폼과 스토어

| 플랫폼 | 클라이언트 또는 스토어 | 지원 시작 | 로그인 방식 |
| --- | --- | --- | --- |
| PC(Windows) | GRYPHLINK 런처(공식 홈페이지에서 다운로드) | 정식 출시, 2026-01-22 | Gryphline 계정 |
| PC(Windows) | Epic Games Store | 정식 출시, 2026-01-22 | Gryphline 계정 |
| PlayStation 5 | PlayStation Store | 정식 출시, 2026-01-22 | PSN 계정만 가능 |
| iOS 및 iPadOS | App Store | 정식 출시, 2026-01-22 | Gryphline 계정 |
| Android | Android 클라이언트 | 정식 출시, 2026-01-22 | Gryphline 계정 |
| PC(Windows) | Steam, 앱 4732690 | 1.6 버전 업데이트 후, 2026-10-15 | Gryphline 계정에 연동된 Steam 계정 |
| 클라우드 | NVIDIA GeForce NOW: Windows PC, Mac, Chromebook용 클라이언트 또는 Chrome, Edge의 웹 버전 | 2026-04-03 | Gryphline 계정 |

- Gryphline 계정은 Google, Apple, Facebook 같은 제3자 계정으로 로그인할 수 있다.
- 모든 플랫폼에서 두 서버 모두 접속할 수 있다. GeForce NOW는 GeForce NOW 멤버십이 필요하며, 이용 가능 여부는 국가나 지역에 따라 다르다.
- Steam 버전은 다른 플랫폼과 같은 서버에서 실행되며, GRYPHLINK가 아니라 Steam 클라이언트를 통해서만 다운로드하고 업데이트한다. 결제는 Steam 오버레이를 통해 이루어진다.

## PC, PlayStation 5, 모바일 간 진행도가 공유되는가

같은 서버 안에서는 공유된다. Asia 서버와 Americas / Europe 서버의 계정 데이터는 공유되지 않는다([서버와 시간](/ko/systems/servers-and-time/)). 한 플랫폼에서 구매한 항목은 같은 Gryphline 계정으로 다른 플랫폼에서도 사용할 수 있다.

| 플랫폼 | 진행도 공유 방법 |
| --- | --- |
| PC, Android, iOS, GeForce NOW | 같은 Gryphline 계정으로 로그인하고 캐릭터가 있는 서버를 선택 |
| Steam | 최초 실행 시 「기존 이메일 계정으로 로그인 및 연동하기」를 선택한 뒤 기존 Gryphline 계정의 이메일을 입력. 「회원가입 및 연동하기」를 선택하면 새 계정이 생성됨 |
| PlayStation 5 | PSN 계정을 Gryphline 계정에 연동. 서버는 PSN 계정의 지역을 따름 |

## 컨트롤러를 사용할 수 있는가

사용할 수 있다. PC와 모바일 기기에서는 다음 컨트롤러를 지원하며, 제3자 컨트롤러는 호환성 문제가 발생할 수 있다.

| 컨트롤러 | PC 블루투스 연결 | 모바일 블루투스 연결 |
| --- | --- | --- |
| DualSense, DualSense Edge(PS5), DUALSHOCK 4(PS4) | 적응형 트리거만 지원. 진동과 컨트롤러 스피커는 미지원 | PC와 동일 |
| Xbox 무선 컨트롤러, Xbox Elite 무선 컨트롤러 | 전체 기능 지원 | 진동과 임펄스 트리거 미지원 |

- 모바일의 Xbox 컨트롤러에 대해 영어 컨트롤러 FAQ는 임펄스 트리거(impulse triggers)를, 번체 중국어 FAQ는 적응형 트리거를 명시한다.
- 두 종류 모두 USB 케이블이나 블루투스로 연결할 수 있다. PlayStation 5 외의 플랫폼에서는 유선 연결 시 PlayStation 컨트롤러의 모든 기능을 사용할 수 있다.
- 로그인 화면에서 컨트롤러 입력을 하면 컨트롤러 레이아웃으로 전환된다. 플레이 중에는 버튼을 누르면 전환 안내가 뜨고, 키보드 입력이나 화면 터치 시 원래 조작으로 돌아가는 안내가 뜬다.
- 오퍼레이터 선택 및 이름 작성 화면, 튜토리얼, 대화 및 스토리 연출 중, 일부 전투와 시뮬레이션에서는 레이아웃을 전환할 수 없다.
- 텍스트 입력은 PC에서는 키보드로, 모바일과 PlayStation에서는 시스템 가상 키보드로 진행한다.
- 진동과 적응형 트리거는 설정 → 조작에서, 컨트롤러 스피커는 설정 → 오디오에서 켜고 끈다.
- 1.2 버전에서 설정 → 컨트롤러에 사용자 지정 버튼 설정이 추가되었다.

## PSN 계정과 Gryphline 계정 연동

| 상황 | 가능한 방법 |
| --- | --- |
| 게임에 로그인한 적이 없는 PSN 계정 | 최초 로그인 시 이용약관 동의 후 나타나는 팝업에서 기존 Gryphline 계정의 이메일을 연동. 건너뛰면 새 Gryphline 계정이 생성되며 팝업은 다시 표시되지 않음 |
| 이미 진행도가 있는 PSN 계정 | 설정 → 플랫폼 및 계정 → 계정 센터 → 이메일 연동에서 Gryphline 계정에 가입되지 않은 이메일을 연동 |
| 연동 해제 | Gryphline 계정 센터에서 계정당 1회만 가능 |
| 제한 | PSN 계정 1개는 Gryphline 계정 1개에만, Gryphline 계정 이메일 1개는 PSN 계정 1개에만 연동 가능 |

- 연동 후에도 PlayStation 5는 PSN 계정으로만, PC와 모바일은 Gryphline 계정으로만 로그인할 수 있다.
- 다른 플랫폼에서 달성한 진행도에 해당하는 PlayStation 트로피는 다음에 PlayStation 5로 로그인할 때 잠금 해제된다.
- PlayStation 5에서는 두 가지 친구 목록이 표시된다. 「명일방주: 엔드필드 친구」는 모든 플랫폼에서 볼 수 있고, 「PlayStation Network 친구」는 PlayStation 5에서만 볼 수 있다.

## Steam

| 단계 | 내용 |
| --- | --- |
| 「사전 테스트」 | 정식 출시 전 인원 제한으로 진행된 테스트. 정식 서버를 사용하며 결제 가능, 데이터 초기화 없음 |
| 정식 출시 | 2026-10-15의 1.6 버전 업데이트 후 두 서버 모두 지원. 「사전 테스트」의 진행도와 구매 내역은 유지됨 |

- Google, Apple, Facebook으로만 로그인해 온 Gryphline 계정은 Steam과 연동하기 전에 Gryphline 통합 계정 센터에서 이메일을 연동해야 한다.
- Steam 연동 해제는 게임 내 설정 → 플랫폼 및 계정 → 계정 센터 또는 Gryphline 통합 계정 센터 웹사이트에서 할 수 있다.

## 게임 업데이트 방법

1.4 버전에서 리소스가 통합되어 모바일 클라이언트 용량이 줄어들었다.

| 플랫폼 | 업데이트 방법 |
| --- | --- |
| PC, GRYPHLINK | 게임을 종료한 뒤 GRYPHLINK를 재실행하고 업데이트 클릭 |
| PC, Steam | Steam 라이브러리에서 새 버전 다운로드 |
| Android | 게임 내 안내 팝업을 따름 |
| iOS | App Store에서 업데이트 |
| PlayStation 5 | 홈 화면에서 게임을 선택하고 OPTIONS 버튼을 누른 뒤 업데이트 확인하기 선택 |

## 런처와 보조 도구

- GRYPHLINK 런처에는 게임 실시간 데이터 패널이 있다(2026-07-10 추가). Gryphline 계정으로 로그인한 뒤 「캐릭터 대시보드 보기」를 누르면 게임이 꺼져 있을 때도 이성, 일상 활약도, 주간 업무를 확인할 수 있으며 계정의 캐릭터 간 전환도 가능하다.
- 게임 내 「프로토콜 동기화 장치」에서 여는 게임 도구는 WIKI, 지도 도구, 「프로토콜 단말기」, 공유된 팀 편성을 제공한다.

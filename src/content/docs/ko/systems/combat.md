《명일방주: 엔드필드》의 피해는 물리, 아츠, 초자연으로 나뉘며 아츠 피해는 다시 열기, 전기, 냉기, 자연으로 나뉜다. 아츠 공격은 적에게 아츠 부착을 남기며 최대 4중첩까지 쌓인다. 같은 속성의 부착을 다시 가하면 아츠 폭발이 일어나고, 다른 속성의 부착을 가하면 아츠 이상(연소, 감전, 동결, 부식)이 발동한다. 물리 이상 공격은 첫 타격으로 적을 방어 불능 상태로 만들고, 이후 띄우기와 넘어뜨리기로 중첩을 쌓으며 강타와 갑옷 파괴로 중첩을 소모한다. 불균형치가 가득 차면 적이 불균형 상태에 빠져 처형을 넣을 수 있다. 피해는 기본 피해(보통 공격력 기준), 치명타, 피해 보너스, 대상의 방어력과 저항, 불균형 상태 등의 배율을 곱해 계산한다. 1.0 버전 NGA 포럼 플레이어 검증에서는 방어력 배율을 100 / (방어력 + 100)(일반적인 적의 기본 방어력 100 기준 0.5), 불균형 상태의 적이 받는 피해를 ×1.3으로 측정했다.

## 피해 공식

아래 공식은 1.0 버전에서 NGA 포럼 플레이어 666bj가 측정한 것이다. 일반 피해(물리 이상, 아츠 이상, 아츠 폭발을 제외한 모든 타격)는 다음 배율을 모두 곱한 값이다.

| 배율 | 값 | 여러 효과의 합산 방식 |
| --- | --- | --- |
| 기본 피해 | 피해 배율 × 효과가 참조하는 능력치(보통 공격력) + 기본 피해 고정 증가 | |
| 치명타 | 치명타 시 1 + 치명타 피해, 아닐 때 1. 평균 1 + 치명타 확률 × 치명타 피해 | |
| 피해 보너스 | 1 + 모든 피해 보너스의 합(피해 유형, 스킬 유형, 불균형 상태 적 대상 피해 등) | 합연산 |
| 피해 감소 | 각 (1 − 감소량)의 곱 | 곱연산 |
| 증폭 효과 | 1 + 증폭 효과의 합 | 합연산 |
| 허약 효과 | 각 (1 − 허약 효과)의 곱 | 곱연산 |
| 비호 | 1 − 가장 높은 비호 | 최고치만 적용 |
| 취약 효과 | 1 + 취약 효과의 합 | 합연산 |
| 기타 받는 피해 증가 | 1 + 취약 효과로 표기되지 않고 받는 피해를 늘리는 효과의 합(감전의 아츠 피해 증가, 갑옷 파괴의 물리 피해 증가 등) | 합연산 |
| 방어력 | 유효 방어력이 0 이상일 때 100 / (방어력 + 100). 방어력 무시 피해는 1 | |
| 불균형 | 불균형 상태의 적에게 1.3, 그 외에는 1 | |
| 저항 | 1 − 저항 / 100 + 무시한 저항 / 100 | |
| 비조작 | 1. 메인 컨트롤 오퍼레이터가 아닌 오퍼레이터를 향한 일부 강한 적의 공격에서는 0~0.7 | |
| 연타 | 연타 1~4중첩 시 배틀 스킬 +30%, +45%, +60%, +75%, 궁극기 +20%, +30%, +40%, +50% | 중첩되나 단계당 증가폭 감소 |
| 특수 | 위 배율과 별도로 적용되는 기타 효과 | 곱연산 |

- 공격력 = [(오퍼레이터 기본 공격력 + 무기 기본 공격력) × (1 + 공격력 % 보너스) + 공격력 고정 보너스] × (1 + 능력치 보너스). 능력치 점수는 주요 능력치 × 0.005 + 보조 능력치 × 0.002만큼 능력치 보너스를 주며 정수 부분만 계산한다. 일부 오퍼레이터 재능은 능력치 보너스를 추가로 더한다.
- 오퍼레이터의 기본 치명타 확률은 5%, 치명타 피해는 50%이다. 적의 치명타 확률은 0%, 치명타 피해는 50%이다.
- 모든 스킬 피해 보너스는 배틀 스킬, 연계 스킬, 궁극기에 적용되며 일반 공격에는 적용되지 않는다. 처형에는 일반 공격 피해 보너스가 적용된다.
- 적의 기본 방어력은 모든 레벨에서 100이므로 방어력을 바꾸는 효과가 없으면 방어력을 적용받는 타격의 방어력 배율은 0.5이다. 오퍼레이터의 기본 방어력은 0이며, 방어력은 보통 장비의 주 능력치에서 얻는다.
- 저항 1포인트마다 해당 유형의 피해가 1% 줄어든다. 게임에서는 적의 저항을 등급으로 표시하며 0은 D, 20~40은 C, 50과 60은 B이다. 대부분의 적 저항은 0 또는 20이고, 일부 적만 한 속성에 30, 35, 40, 50 또는 60을 가진다. 초자연 저항이 있는 적은 없다. 모든 적의 수치는 [적 저항](/ko/systems/enemies/)에 있다.
- 오퍼레이터의 물리 저항은 100 − 100 / (0.001 × 민첩 + 1)이고, 아츠 저항은 지능으로 같은 식을 쓰며 민첩과 지능은 정수 부분만 계산한다. 오퍼레이터의 저항 배율은 0.1 미만으로 내려가지 않는다.
- 게임 내 많은 수치는 소수점을 버리고 표시되므로 표시된 숫자로 계산하면 몇 포인트 차이가 날 수 있다.

오퍼레이터가 발동하는 물리 이상, 아츠 이상, 아츠 폭발은 위 배율 중 비조작과 연타를 빼고 다음 두 배율을 추가로 곱한다.

| 배율 | 값 |
| --- | --- |
| 레벨 | 아츠 이상과 아츠 폭발: 1 + (발동한 오퍼레이터의 레벨 − 1) / 196(90레벨 기준 1.454). 물리 이상: 1 + (레벨 − 1) / 392(90레벨 기준 1.227) |
| 오리지늄 아츠 강도 | 1 + 오리지늄 아츠 강도 / 100 |

| 피해 | 피해 배율(공격력 기준) |
| --- | --- |
| 연소, 감전, 동결, 부식: 첫 타격 | 80% × (1 + 이상 레벨) |
| 연소: 초당 지속 피해 | 12% × (1 + 이상 레벨) |
| 쇄빙(물리 피해이지만 레벨 배율은 아츠 이상으로 계산) | 120% × (1 + 이상 레벨) |
| 모든 아츠 폭발 | 160% |
| 띄우기, 넘어뜨리기 | 120%, 불균형치 10 추가 |
| 갑옷 파괴 | 50% × (1 + 이상 레벨) |
| 강타 | 150% × (1 + 이상 레벨) |

| 이상 레벨 1 / 2 / 3 / 4 효과 | 값 |
| --- | --- |
| 감전: 적이 받는 아츠 피해 증가 | +12% / 16% / 20% / 24%, 12 / 18 / 24 / 30초 지속 |
| 갑옷 파괴: 적이 받는 물리 피해 증가 | +12% / 16% / 20% / 24%, 12 / 18 / 24 / 30초 지속 |
| 부식: 모든 저항 감소 | 즉시 3.6 / 4.8 / 6 / 7.2 감소 후 초당 0.84 / 1.12 / 1.4 / 1.68 감소, 최대 12 / 16 / 20 / 24. 초기 지속 15초. 부식을 갱신해도 이미 쌓인 저항 감소량은 유지된다 |
| 연소 | 10초 |
| 동결 | 6 / 7 / 8 / 9초 |

- 오리지늄 아츠 강도는 갑옷 파괴, 감전, 부식의 부가 효과도 강화해 효과에 1 + 2 × 오리지늄 아츠 강도 / (오리지늄 아츠 강도 + 300)을 곱한다. 잠재 능력의 ×1.33처럼 해당 부가 효과를 배수로 높이는 효과는 그 뒤에 곱한다. 띄우기와 넘어뜨리기는 오리지늄 아츠 강도 1포인트마다 불균형치가 0.5% 늘어난다.
- 스킬이 아츠 부착을 소모하지 않고 직접 부여하는 아츠 이상은 기본적으로 첫 타격 피해가 없다.

## 피해 유형과 속성

| 피해 유형 | 분류 | 해당 속성 오퍼레이터 수(게임 데이터 1.6) |
| --- | --- | --- |
| 물리 | 물리 | 9 |
| 열기 | 아츠 | 5 |
| 전기 | 아츠 | 7 |
| 냉기 | 아츠 | 8 |
| 자연 | 아츠 | 5 |
| 초자연 | 초자연 | 0 |

게임 데이터 1.6의 오퍼레이터 34명은 모두 물리 또는 네 가지 아츠 속성 중 하나를 지니며, 초자연 속성 오퍼레이터는 없다. 각 속성의 오퍼레이터는 아래 속성별 오퍼레이터 표에 정리되어 있다.

## 아츠 부착, 아츠 폭발, 아츠 이상

| 용어 | 설명 |
| --- | --- |
| 아츠 부착 | 적에게 남기는 네 가지 속성 중 하나의 아츠 표식. 속성마다 최대 4중첩. |
| 아츠 폭발 | 이미 같은 속성의 부착이 있는 적에게 동일 속성 부착을 추가할 때 발동하며 해당 속성 피해를 준다. |
| 아츠 이상 | 한 적에게 서로 다른 두 속성의 부착이 겹칠 때 부착을 소모하며 발동하는 아츠 디버프. 게임에서는 다른 부착에 특정 속성 부착을 더하는 형태로 표기한다(예: 연소 = 다른 부착 + 열기 부착). |
| 이상 레벨 | 아츠 이상이나 물리 이상이 소모한 부착 중첩 수(또는 방어 불능 중첩 수). 최대 4이며 레벨이 높을수록 효과가 강하다. |

| 속성 | 아츠 폭발 | 아츠 이상(해당 속성 + 다른 속성 부착) | 적에게 주는 이상 효과 | 오퍼레이터에게 4중첩 시 |
| --- | --- | --- | --- | --- |
| 열기 | 열기 폭발: 열기 피해 | 연소 | 열기 지속 피해를 받는다 | 연소: 방어력을 무시하는 열기 지속 피해를 받는다 |
| 전기 | 전기 폭발: 전기 피해 | 감전 | 받는 아츠 피해가 증가한다 | 감전: 잠시 기절하고 일정 시간 받는 아츠 피해가 증가한다 |
| 냉기 | 냉기 폭발: 냉기 피해 | 동결 | 움직일 수 없다. 이때 방어 불능이나 물리 이상을 가하면 쇄빙이 발동한다 | 동결: 일정 시간 움직일 수 없다 |
| 자연 | 자연 폭발: 자연 피해 | 부식 | 모든 저항이 서서히 감소한다 | 부식: 일정 시간 대시할 수 없고 이동 속도가 느려진다 |

적의 스킬도 오퍼레이터에게 아츠 부착을 쌓을 수 있다. 마지막 열은 한 속성이 4중첩에 도달했을 때 오퍼레이터가 받는 효과다.

## 물리 이상과 방어 불능

적에게 가하는 첫 물리 이상 타격은 해당 이상을 적용하지 않고 적을 방어 불능 상태로 만든다. 방어 불능은 최대 4중첩까지 쌓인다.

| 물리 이상 | 방어 불능 상태의 적에게 |
| --- | --- |
| 띄우기 | 방어 불능 1중첩 추가, 물리 피해와 불균형치 부여 |
| 넘어뜨리기 | 방어 불능 1중첩 추가, 물리 피해와 불균형치 부여(띄우기와 같은 규칙) |
| 강타 | 모든 방어 불능 중첩을 소모해 큰 물리 피해를 준다 |
| 갑옷 파괴 | 모든 방어 불능 중첩을 소모해 물리 피해를 주고 일정 시간 적이 받는 물리 피해를 늘린다 |
| 쇄빙 | 독립된 이상이 아니다. 동결된 적에게 방어 불능이나 물리 이상을 가하면 동결을 소모해 큰 물리 피해를 준다 |

강타와 갑옷 파괴도 아츠 이상처럼 이상 레벨을 가지며, 소모한 방어 불능 중첩 수가 이상 레벨이 된다.

## 불균형, 처형, 강력한 일격

| 용어 | 설명 |
| --- | --- |
| 불균형치 | 대부분의 스킬과 메인 컨트롤 오퍼레이터의 강력한 일격으로 누적된다. 게이지가 가득 차면 적이 불균형 상태가 된다. |
| 불균형 상태 | 일정 시간 적이 움직이지 못하고 더 큰 피해를 받는다. 매우 빠르게 불균형 상태가 된 적은 첫 불균형 상태가 끝난 뒤 한동안 불균형치가 천천히 쌓인다. |
| 불균형 지점 | 일부 강한 적의 불균형 게이지에 있는 표시. 도달하면 적의 행동을 끊고 비틀거리게 만든다. |
| 처형 | 불균형 상태의 적에게 가하는 첫 일반 공격. 큰 피해를 주고 스킬 게이지를 일부 회복한다. |
| 강력한 일격 | 일반 공격 연속 타격의 마지막 공격. 메인 컨트롤 오퍼레이터가 적중시키면 불균형치를 주고 스킬 게이지를 회복한다. |

## 스킬 게이지, 스킬, 궁극기 에너지

| 스킬 | 소모 | 쿨타임 | 게임 데이터 1.6 비고 |
| --- | --- | --- | --- |
| 일반 공격 | 없음 | 없음 | 메인 컨트롤 오퍼레이터가 아닌 팀원은 자동으로 공격한다 |
| 배틀 스킬 | 스킬 게이지 | 없음 | 34명 중 33명은 스킬 게이지 100, [리노](/ko/operators/liino/)만 25 |
| 연계 스킬 | 없음 | 있음 | 해당 오퍼레이터 고유의 발동 조건을 충족할 때만 사용한다. 스킬 레벨 1 기준 쿨타임 3~40초 |
| 궁극기 | 궁극기 에너지 전부 | 사용 후 짧은 쿨타임 | 게이지를 가득 채워야 한다. 오퍼레이터마다 궁극기 에너지 70~300, 쿨타임 10, 15, 20 또는 30초 |

- 스킬 게이지는 배틀 스킬 사용에 소모된다. 시간이 지나면 회복되며, 메인 컨트롤 오퍼레이터의 강력한 일격과 처형으로도 추가 회복된다.
- 궁극기 에너지는 배틀 스킬(모든 팀원에게 같은 양)과 연계 스킬(시전자 본인만)에서 얻는다. 궁극기로 자신을 강화하는 오퍼레이터는 강화가 유지되는 동안 궁극기 에너지를 얻지 못한다.
- 팀은 최대 4명의 오퍼레이터로 구성한다. 모든 팀원의 배틀 스킬, 연계 스킬, 궁극기는 직접 사용한다.

## 버프, 디버프와 기타 용어

| 용어 | 효과 | 같은 유형 중첩 |
| --- | --- | --- |
| 증폭 효과 | 일정 시간 대상이 주는 특정 속성 피해가 증가한다(물리 증폭, 열기 증폭 효과, 아츠 증폭 효과 등) | 합연산 |
| 취약 효과 | 일정 시간 대상이 받는 특정 속성 피해가 증가한다 | 합연산 |
| 비호 | 일정 시간 대상이 받는 피해가 감소한다 | 최고치만 적용 |
| 허약 효과 | 일정 시간 대상이 주는 피해가 감소한다 | 중첩되나 선형은 아니다 |
| 보호 | 지속 시간 동안 피해를 흡수한다. 특정 피해 유형만 흡수하는 보호도 있다 | |
| 감속 효과 | 일정 시간 이동 속도가 감소한다 | 최고치만 적용 |
| 가속 | 일정 시간 이동 속도가 증가한다 | 속도 상한까지 합연산 |
| 속박 | 지속 시간 동안 대상은 행동할 수 없다 | |
| 정화 | 오퍼레이터의 특정 디버프를 제거한다 | |
| 연타 | 팀의 다음 배틀 스킬 또는 궁극기 피해가 증가하며 배틀 스킬 쪽이 더 크게 오른다. 사용 시 소모된다 | 중첩되나 단계당 증가폭 감소 |
| 스킬 게이지 반환 | 조건을 충족하면 방금 소모한 스킬 게이지의 일부가 돌아온다. 스킬 게이지 회복이 아니므로 회복에 반응하는 효과를 발동하지 않으며, 반환분을 써도 궁극기 에너지를 얻지 못한다 | |
| 상태 소모 | 다른 효과가 소모해 디버프가 일찍 끝나는 것(강타가 방어 불능을 소모하거나 아츠 이상이 부착을 소모하는 경우) | |
| 흡수 | 특수한 방식으로 디버프가 일찍 끝나는 것. 상태 소모로 치지 않는다 | |
| 지속 피해 | 시간에 걸쳐 주는 피해. 치명타가 발생하지 않는다 | |
| 고정 피해 | 방어력과 저항을 무시하며 어떤 피해 증가나 감소 효과의 영향도 받지 않는다 | |

특정 오퍼레이터에게만 속한 상태:

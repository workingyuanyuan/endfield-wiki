## 생산 설비의 작동 방식

생산 설비는 한 번에 하나의 제작법(조합 공식)만 실행하며, 설비 안의 아이템이 제작법 중 하나와 맞으면 곧바로 생산을 시작한다. 아이템은 다른 설비나 창고에서 컨베이어 벨트로, 액체는 파이프로 들어오고, 제품은 컨베이어 벨트로 다음 설비나 창고 입력 포트, 프로토콜 저장함으로 나간다.

## 설비의 입력과 출력 방식

- 프로토콜 코어, 서브 코어와 대부분의 생산 설비에는 입력 포트와 출력 포트가 있다. 출력 포트에서 이은 컨베이어 벨트는 아이템을 내보내고, 입력 포트로 들어오는 컨베이어 벨트는 아이템을 넣는다.
- 프로토콜 코어와 서브 코어의 포트는 지역 창고에 연결되어 있다. 출력 포트에서 아이템을 지정하면 창고에서 그 아이템을 꺼내 보낸다. 다른 설비의 포트는 자체 저장 공간에만 연결된다.
- 가방이나 창고에서 아이템을 직접 설비로 끌어다 넣고 제품을 꺼낼 수도 있다.
- 설비 화면의 왼쪽에는 입력 포트와 들어오는 재료가, 오른쪽에는 출력 포트와 나가는 제품이 표시된다.
- 설비가 막히면 입출력을 멈추고 화면에 경고가 뜬다.
- 무릉의 일부 설비에는 파이프를 연결하는 액체 포트가 달린 액체 모드가 있으며, 모드를 바꾸면 실행할 수 있는 제작법이 바뀐다. 1.4 버전부터는 설비를 배치하기 전에 모드를 선택할 수 있다.

| 창고 출력 포트 | 지정한 창고 아이템을 컨베이어 벨트로 내보낸다 | 창고 입출력 라인 바로 옆에 배치한다 |
| 창고 입력 포트 | 컨베이어 벨트로 들어온 아이템을 창고에 저장한다 | 창고 입출력 라인 바로 옆에 배치한다 |
| 프로토콜 저장함 | 아이템을 보관하며, 전력이 공급되면 창고로 전송한다. 생산 라인 끝에 자주 놓는다 | 소비 전력 5 |
| 액체 저장 탱크와 저장용 가스통 | 액체와 기체를 저장한다 | |

## 프로토콜 용량

지역마다 별도의 프로토콜 용량이 있다. 통합 핵심 구역 밖에 설비를 배치하면 용량을 소모하며, 설비 종류마다 소모량이 다르다. 지역의 용량을 다 쓰면 그 지역에는 더 이상 설비를 배치할 수 없다. 지역 건설 레벨이 오르면 한도가 늘어난다([지역 건설](/ko/aic/regional-development/) 참조).

## 확장 반응기: 복수의 조합 공식 막힘 자동 처리

1.3 버전부터 확장 반응기가 여러 제작법을 실행하는 중 모두 막히면 캐시를 비워 반응이 이어지게 한다. 이 옵션은 기본으로 켜져 있으며 청사진에 함께 저장된다.

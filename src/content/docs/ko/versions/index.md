각 버전에는 번호와 제목이 있다. 예를 들어 1.6 버전의 제목은 「단청도」이다. 각 업데이트 점검은 아래 표 날짜의 06:00부터 12:00까지 진행되었다. 1.0 버전은 2026-01-22 11:00의 정식 출시이다.

## 업데이트 점검

1.4 버전은 [정식 출시](/ko/versions/1-0/) 후 네 번째 업데이트이자 메인 챕터 버전이다. 업데이트 점검은 당일 06:00부터 12:00까지 진행되었다.

## 신규 콘텐츠

이 버전부터는 1장을 끝내지 않아도 「1장 - 프로세스 II - 수리 진행 상황」 직후에 무릉의 2장 메인 임무를 시작할 수 있다.

| 종류 | 추가 내용 |
| --- | --- |
| 메인 임무 | 「2장 - 프로세스 VII - 지지 않는 노을」까지 개방 |
| 구역 | 무릉 - 응룡 관문, 무릉 - 북쪽 금지 구역 |
| 오퍼레이터 | [결](/ko/operators/arcane/)과 [리노](/ko/operators/liino/)(모두 6성) |
| 6성 무기 | 42식 · 척결(아츠 유닛), 찬란한 밤의 데뷔(장병기), 조망(한손검), 공명점(아츠 유닛), 전성기(장병기) |
| 적 | 「알레이크레오스, 천부장」(1종)과 그림자에 물든 응룡 대장을 포함한 그림자 계열 8종 |
| 통합 공업 | 무릉의 기체 생산(기체 수집, 기체 반응로 등 공업 계획), 기체 자원 비활성 기체와 기체 식양, 거점 「영천대 건설 기지」 |
| 장비 세트 | 통합 실전 훈련, 절망 |
| 재료 | 탈로스 버섯(정예화), 붉은 창 잎(스킬 마스터리), 프로토콜 문양석(무기 돌파) |

## 시스템 변경

- 무릉 선행 해제: 무릉의 대부분 적은 탐색 레벨에 따라 레벨이 조정되며, 무릉에 프로토콜 코어를 배치하면 통합 공업 설비 일부가 선행 해제된다. 이 설비는 해당 연구를 완료해야 4번 협곡에서 사용할 수 있다.
- 전투: 아군 스킬 효과의 품질과 불투명도를 설정할 수 있고, 타겟팅 설정이 3가지(스킬 우선 공격 목표, 메인 목표 고정, 보조 목표 선택)로 나뉘었다.
- 신규 기능: 유령수정 교환(응룡 관문과 북쪽 금지 구역에서 수집한 유령수정 교환), 재료 전환(간편 제작에서 높은 등급 재료를 낮은 등급 재료로 전환), 생일, ID 정보 갱신 카드(반년마다 1장 무료), 보유 오퍼레이터 2D 일러스트 보기.
- 오퍼레이터 체험 이벤트 보상에 무기고 방어구 상자가 추가되었다. 체험 오퍼레이터에 적합한 정밀 단조 최대치 60레벨 세트 장비가 들어 있다.
- 통합 공업: 무릉의 지역 건설 레벨 최대치가 상승했다. 암관 연결 거리는 직선거리로 계산되며 최대치가 200 m에서 300 m로 늘었다. 프로토콜 코어 구역 밖의 설비를 지도에서 원격 수납할 수 있다. 노란색 품질 장비는 제작 기술을 전환할 수 있고, 최신 기술은 관리권 소모를 99% 줄여 준다.
- 장식 아이템이 가방과 창고 용량을 차지하지 않는다. 헤드헌팅 기록과 신청 기록은 최근 90일간의 특별 허가 헤드헌팅 및 무기고 신청 보상을 보관한다.
- O.M.V.제강호: 응접실 단서 교류 시간이 24시간에서 20시간으로 줄었고, 핵심 제어 중추에서 선실을 원격으로 업그레이드할 수 있다.
- 그래픽: PC에서 NVIDIA DLSS 4.5 초해상도와 AMD FSR 3을 지원하며, PlayStation 5 Pro에서 업그레이드된 PSSR을 지원한다.
- 오류 수정: [알레쉬](/ko/operators/alesh/)가 잠재 능력 「린수의 반격」을 잠금 해제한 뒤 배틀 스킬로 일부 무기 스킬 효과가 발동하지 않던 문제를 수정했다.
- 오류 수정: [스노우샤인](/ko/operators/snowshine/)을 메인 컨트롤 오퍼레이터로 조작할 때 특정 동작 후 화면이 회전하던 문제, 팀의 [카치르](/ko/operators/catcher/)가 강력한 일격을 사용할 때 카메라가 흔들리던 문제, 모바일에서 [장방이](/ko/operators/zhuang-fangyi/)의 낙하 공격에 진동이 없던 문제, 화면 전환 시 카뮤의 날개가 비정상적으로 표시되던 문제를 수정했다.
- 미브의 연계 스킬 효과음을 개선했다.

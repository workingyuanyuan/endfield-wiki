## 시스템 변경 사항

- 통합 공업: 통합 핵심 구역으로 돌아가지 않고 지도 어느 위치에서든 보유한 재료로 설비를 제작할 수 있다.
- 통합 공업: 지도 화면에서 다른 플레이어가 남긴 공용 설비를 바로 삭제할 수 있고 공용 집라인과 직접 설치한 집라인의 표시가 구분된다. 집라인에 탑승해 이동하기 전 미니맵이 표시된다.
- 통합 공업: 전선이 끊기지 않고 유지되는 거리가 늘어나 중계기는 90m에서 100m로, 전력 공급기는 40m에서 50m로 연장되었다(회로 연결 거리는 동일).
- 통합 공업: 탑뷰 모드의 가시거리가 넓어졌다. PC에서는 ESC 키로 종료하도록 설정할 수 있고 마우스 왼쪽 버튼을 길게 눌러 선택한 여러 설비를 한 번에 이동할 수 있다. 컨트롤러 모드에 이동 옵션이 추가되었다.
- 지역 건설: 무릉 지역, 물자 관리, 저장고 노드, 환경 관측, 천왕 평지 건설 지원소 거점의 레벨 최대치가 올라갔다. 4번 협곡 - 광맥 구역의 물자 관리가 4레벨이 되면 협곡 다중 흔적 각인 상자로 선택한 속성 3개가 포함된 기질 1개를 얻을 수 있다.
- 오퍼레이터 육성, 무기 육성, 위험한 재현, 위험한 리허설 관련 프로토콜 공간은 외부 상태와 별개로 생명력과 궁극기 에너지가 가득 찬 상태로 시작한다.
- 제때 줍지 못한 희귀 식물, 희귀 광물과 일부 프로토콜 공간 재료는 메일함 임시 보관소로 자동 발송된다.
- 응룡 50식, 검술사, 위기 탈출을 포함한 10개 장비 세트에 일부 장비 부품이 추가되었다. 모든 오퍼레이터에 전환 시 음성과 피격 시 표정 연출이 추가되었다.
- 설정: 조작에 카메라 거리, 성능 및 화면에 표시 모드가 추가되었다.
- 이본의 궁극기 설명이 수정되었다(실제 효과는 동일). [안탈](/ko/operators/antal/)의 중국어 성우 표기가 변경되었다. 4성 무기 「긴급 대책」의 이름이 「드러난 칼날」로 변경되었다.
- 레바테인 수정: 강화 배틀 스킬의 추가 공격 순간 돌진하거나 해당 추가 공격으로 열기 부착 상태의 적을 처치했을 때 불꽃 중첩이 비정상적으로 적용되던 문제와, 궁극기 종료 직전 배틀 스킬을 사용하면 궁극기가 조기 종료되던 문제를 수정했다.
- 기타 오퍼레이터 수정: 이본이 처형을 발동할 수 없던 문제, 라스트 라이트의 연계 스킬이 적을 응결하지 못하던 문제, 엠버가 배틀 스킬 중 다단 피격 시 비정상 표시되고 3단계 일반 공격에서 목표가 고정되지 않던 문제, [판](/ko/operators/da-pan/)의 궁극기와 연계 스킬에서 목표가 고정되지 않던 문제, [아비웨나](/ko/operators/avywenna/)의 잠재 능력 「회유와 위압」을 설명과 일치시키고 「더블 베팅」이 비정상 발동하던 문제를 수정했다.
- 플랫폼: 이 버전 기간 중 NVIDIA GeForce NOW에서 플레이할 수 있게 되었으며 같은 서버 내 다른 플랫폼과 진행도가 공유된다.

《明日方舟：終末地》的傷害分為物理傷害、法術傷害與超域傷害，法術傷害又分灼熱、電磁、寒冷、自然。法術攻擊會在敵人身上留下法術附著，同屬性最多 4 層：再疊加同屬性的附著會觸發法術爆發，遇上其他屬性的附著則觸發法術異常（燃燒、導電、凍結或腐蝕）。物理異常第一次命中只會讓敵人破防；之後擊飛與倒地疊加破防層數，猛擊與碎甲消耗層數。失衡值累積滿時敵人進入失衡狀態，可以被處決。傷害是多個乘區相乘的結果：基礎傷害（多數依攻擊力計算）、暴擊、傷害加成、目標的防禦力與抗性，以及失衡狀態。NGA 論壇玩家在 1.0 版實測：防禦乘區為 100 / (防禦力 + 100)，敵人常見的基礎防禦力 100 時為 0.5；失衡狀態的敵人受到 ×1.3 傷害。

## 傷害公式

以下公式為 NGA 論壇玩家 666bj 在 1.0 版的實測整理。一般傷害指物理異常、法術異常與法術爆發以外的所有傷害，等於下列乘區相乘：

| 乘區 | 數值 | 多個效果如何疊加 |
| --- | --- | --- |
| 基礎傷害 | 傷害倍率 × 效果所依據的屬性（通常是攻擊力），再加上基礎傷害提升值 | |
| 暴擊 | 暴擊時為 1 + 暴擊傷害，否則為 1；平均為 1 + 暴擊率 × 暴擊傷害 | |
| 傷害加成 | 1 + 所有傷害加成之和：傷害類型、技能類型、對失衡目標的傷害與其他 | 相加 |
| 傷害減免 | 各項 (1 − 減免) 相乘 | 相乘 |
| 增幅 | 1 + 增幅效果之和 | 相加 |
| 虛弱 | 各項 (1 − 虛弱) 相乘 | 相乘 |
| 庇護 | 1 − 最強的庇護 | 只取最高值 |
| 脆弱 | 1 + 脆弱效果之和 | 相加 |
| 其他受到傷害提高 | 1 + 未標為脆弱、但提高受到傷害的效果之和，例如導電提高的法術傷害、碎甲提高的物理傷害 | 相加 |
| 防禦 | 有效防禦力為 0 或以上時為 100 / (防禦力 + 100)；無視防禦力的傷害為 1 | |
| 失衡 | 敵人處於失衡狀態時為 1.3，否則為 1 | |
| 抗性 | 1 − 抗性 / 100 + 無視的抗性 / 100 | |
| 非主控 | 1；部分強大敵人的攻擊打在非主控幹員身上時為 0 至 0.7 | |
| 連擊 | 1 至 4 層連擊時，戰技 +30%、+45%、+60% 或 +75%，終結技 +20%、+30%、+40% 或 +50% | 可以疊加，效果遞減 |
| 特殊 | 獨立於以上乘區的其他效果 | 相乘 |

- 攻擊力 = [(幹員基礎攻擊力 + 武器基礎攻擊力) × (1 + 攻擊力百分比加成) + 攻擊力固定數值加成] × (1 + 能力值加成)。能力值帶來的能力值加成 = 主能力 × 0.005 + 副能力 × 0.002，能力值只計整數部分；部分幹員的天賦會另外提供能力值加成。
- 幹員的基礎暴擊率為 5%，基礎暴擊傷害為 50%。敵人的暴擊率為 0%，暴擊傷害為 50%。
- 所有技能傷害加成作用於戰技、連攜技與終結技，不包括普通攻擊。處決可以受益於普通攻擊傷害加成。
- 敵人的基礎防禦力在任何等級都是 100，所以沒有改變防禦力的效果時，受防禦力影響的傷害防禦乘區為 0.5。幹員的基礎防禦力為 0，防禦力一般來自裝備的主屬性。
- 每 1 點抗性使該類傷害降低 1%。敵人的抗性分檔：D 檔為 0，C 檔通常為 20（一種敵人的自然抗性為 30），B 檔為 50。敵人的基礎超域抗性為 0。
- 幹員的物理抗性 = 100 − 100 / (0.001 × 敏捷 + 1)，法術抗性以智識同樣計算，敏捷與智識只計整數部分。幹員的抗性乘區最低為 0.1。
- 遊戲中許多數值顯示時無條件捨去小數，所以用顯示的數值計算，結果可能差幾點。

幹員觸發的物理異常、法術異常與法術爆發，傷害使用上述乘區，但沒有非主控與連擊，另外多兩個乘區：

| 乘區 | 數值 |
| --- | --- |
| 等級 | 法術異常與法術爆發：1 + (觸發幹員的等級 − 1) / 196，90 級時為 1.454。物理異常：1 + (等級 − 1) / 392，90 級時為 1.227 |
| 源石技藝強度 | 1 + 源石技藝強度 / 100 |

| 傷害 | 傷害倍率（攻擊力的百分比） |
| --- | --- |
| 燃燒、導電、凍結、腐蝕：初始傷害 | 80% × (1 + 異常等級) |
| 燃燒：每秒的持續傷害 | 12% × (1 + 異常等級) |
| 碎冰（物理傷害，計算等級乘區時視為法術異常） | 120% × (1 + 異常等級) |
| 任何法術爆發 | 160% |
| 擊飛、倒地 | 120%，並累積 10 點失衡值 |
| 碎甲 | 50% × (1 + 異常等級) |
| 猛擊 | 150% × (1 + 異常等級) |

| 異常等級 1 / 2 / 3 / 4 的效果 | 數值 |
| --- | --- |
| 導電：敵人受到的法術傷害提高 | +12% / 16% / 20% / 24%，持續 12 / 18 / 24 / 30 秒 |
| 碎甲：敵人受到的物理傷害提高 | +12% / 16% / 20% / 24%，持續 12 / 18 / 24 / 30 秒 |
| 腐蝕：所有抗性降低 | 立即降低 3.6 / 4.8 / 6 / 7.2，之後每秒降低 0.84 / 1.12 / 1.4 / 1.68，最多降低 12 / 16 / 20 / 24；初始持續 15 秒；刷新腐蝕會維持已累積的抗性下降 |
| 燃燒 | 10 秒 |
| 凍結 | 6 / 7 / 8 / 9 秒 |

- 源石技藝強度也會強化碎甲、導電與腐蝕的附帶效果：效果乘以 1 + 2 × 源石技藝強度 / (源石技藝強度 + 300)。把這類附帶效果提升為原本若干倍的效果（例如潛能的 ×1.33），在此之後再相乘。對擊飛與倒地，每點源石技藝強度使累積的失衡值 +0.5%。
- 技能直接施加、未消耗法術附著的法術異常，預設沒有初始傷害。

| 傷害類型 | 分類 | 該屬性的幹員數（遊戲資料 1.6） |
| --- | --- | --- |
| 物理 | 物理 | 9 |
| 灼熱 | 法術 | 5 |
| 電磁 | 法術 | 7 |
| 寒冷 | 法術 | 8 |
| 自然 | 法術 | 5 |
| 超域 | 超域 | 0 |

遊戲資料 1.6 的 34 名幹員，屬性都是物理或四種法術屬性之一，沒有幹員的屬性是超域。各屬性的幹員列於下方依屬性分的幹員表。

## 法術附著、法術爆發與法術異常

| 用語 | 說明 |
| --- | --- |
| 法術附著 | 附著在敵人身上的法術標記，分四種屬性。同屬性最多疊加 4 層。 |
| 法術爆發 | 對已有某屬性附著的敵人再施加同屬性附著時觸發，造成該屬性傷害。 |
| 法術異常 | 同一名敵人身上有兩種不同屬性的附著時觸發的法術減益，會消耗附著。遊戲把每一種寫成其他法術附著加上某屬性附著，例如燃燒 = 其他法術附著 + 灼熱附著。 |
| 異常等級 | 觸發法術異常或物理異常時消耗的附著層數（或破防層數），最高 4 級。等級越高效果越強。 |

| 屬性 | 法術爆發 | 法術異常（該屬性附著加上其他屬性附著） | 對敵人的效果 | 幹員被疊滿 4 層時 |
| --- | --- | --- | --- | --- |
| 灼熱 | 灼熱爆發：灼熱傷害 | 燃燒 | 持續受到灼熱傷害 | 燃燒：持續受到無視防禦力的灼熱傷害 |
| 電磁 | 電磁爆發：電磁傷害 | 導電 | 受到的法術傷害提高 | 導電：短暫暈眩，且一段時間內受到的法術傷害提高 |
| 寒冷 | 寒冷爆發：寒冷傷害 | 凍結 | 無法行動；此時受到破防或物理異常會觸發碎冰 | 凍結：一段時間內無法行動 |
| 自然 | 自然爆發：自然傷害 | 腐蝕 | 所有抗性逐漸下降 | 腐蝕：一段時間內無法衝刺，移動速度降低 |

敵人的技能也會對幹員疊加法術附著；最後一欄是同屬性疊滿 4 層時幹員受到的效果。

## 物理異常與破防

敵人第一次受到物理異常時，不會觸發異常效果，而是進入破防狀態。破防最多疊加 4 層。

| 物理異常 | 對已破防的敵人 |
| --- | --- |
| 擊飛 | 疊加 1 層破防，造成物理傷害並累積失衡值 |
| 倒地 | 疊加 1 層破防，造成物理傷害並累積失衡值（與擊飛規則相同） |
| 猛擊 | 消耗所有破防層數，造成大量物理傷害 |
| 碎甲 | 消耗所有破防層數，造成物理傷害，並使敵人一段時間內受到的物理傷害提高 |
| 碎冰 | 不是獨立的異常：對凍結中的敵人施加破防或任何物理異常時，消耗凍結並造成大量物理傷害 |

猛擊與碎甲也有異常等級，和法術異常一樣，等於消耗的破防層數。

## 失衡、處決與重擊

| 用語 | 說明 |
| --- | --- |
| 失衡值 | 大部分技能與主控幹員的重擊命中時累積。累積滿時敵人進入失衡狀態。 |
| 失衡狀態 | 一段時間內敵人無法行動，受到的傷害增加。很快就進入失衡的敵人，在第一次失衡結束後的一段時間內，累積的失衡值會降低。 |
| 失衡節點 | 部分強大敵人的失衡條上的節點。累積到節點時會打斷敵人並使其踉蹌。 |
| 處決 | 對失衡狀態的敵人第一次普通攻擊：造成大量傷害並回復一定技力。 |
| 重擊 | 普通攻擊的最後一段。主控幹員的重擊會累積失衡值並回復技力。 |

## 技力、技能與終結技能量

| 技能 | 消耗 | 冷卻 | 遊戲資料 1.6 的數值 |
| --- | --- | --- | --- |
| 普通攻擊 | 無 | 無 | 非主控的隊友會自動普通攻擊 |
| 戰技 | 技力 | 無 | 34 名幹員中 33 名消耗 100 點技力；[梨諾](/zh-tw/operators/liino/) 消耗 25 點 |
| 連攜技 | 無 | 有 | 達成該幹員自己的觸發條件才能施放；技能等級 1 時冷卻 3 至 40 秒 |
| 終結技 | 全部終結技能量 | 施放後短暫冷卻 | 能量需充滿：依幹員為 70 至 300 點；冷卻 10、15、20 或 30 秒 |

- 技力用來施放戰技，會隨時間自動回復；主控幹員的重擊與處決也會回復技力。
- 終結技能量來自施放戰技（全隊獲得等量）與施放連攜技（只有施放者獲得）。終結技會讓自己進入強化狀態的幹員，在強化期間不會獲得終結技能量。
- 一支小隊最多 4 名幹員。每名隊員的戰技、連攜技與終結技都要手動施放。

## 增益、減益與其他用語

| 用語 | 效果 | 同類效果 |
| --- | --- | --- |
| 增幅 | 一段時間內目標造成的某種屬性傷害提高（物理增幅、灼熱增幅、法術增幅等） | 可以疊加 |
| 脆弱 | 一段時間內目標受到的某種屬性傷害提高 | 可以疊加 |
| 庇護 | 一段時間內目標受到的傷害降低 | 只取最高值 |
| 虛弱 | 一段時間內目標造成的傷害降低 | 以非線性方式疊加 |
| 護盾 | 持續期間吸收傷害；部分護盾只吸收特定類型的傷害 | |
| 緩速 | 一段時間內移動速度降低 | 只取最高值 |
| 加速 | 一段時間內移動速度提高 | 可疊加至上限 |
| 定身 | 持續期間目標暫停行動 | |
| 淨化 | 清除幹員身上的特定異常狀態 | |
| 連擊 | 全隊下一次戰技或終結技傷害提高，戰技提高較多；觸發後清空 | 可以疊加，效果遞減 |
| 返還技力 | 消耗技力後達成條件時，取回一部分技力。不算回復技力：不觸發回復技力時的效果，消耗這部分技力也不會獲得終結技能量 | |
| 狀態消耗 | 狀態因其他效果而提前結束：猛擊消耗破防，法術異常消耗法術附著 | |
| 吸收 | 狀態以特殊方式提前結束；不算消耗 | |
| 持續傷害 | 隨時間造成的傷害；無法暴擊 | |
| 固定傷害 | 無視防禦與抗性，也不受任何傷害提高或降低效果影響 | |

只屬於單一幹員的狀態：

| 狀態 | 幹員 | 效果 |
| --- | --- | --- |
| 源石結晶 | [管理員](/zh-tw/operators/endministrator/) | 連攜技讓敵人附著結晶，使其無法行動 |
| 爪印斫痕 | [洛西](/zh-tw/operators/rossi/) | 戰技施加：持續受到物理傷害，且受到的物理與灼熱傷害增加 |
| 啟示 | [提弗洛斯](/zh-tw/operators/typhoeus/) | 消耗敵人的自然附著或敵人受到自然爆發時累積；連攜技把啟示轉換為獵矢 |
| 獵矢 | [提弗洛斯](/zh-tw/operators/typhoeus/) | 浮空時消耗，強化射擊，傷害更高並額外觸發自然爆發 |

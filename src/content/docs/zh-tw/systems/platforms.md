《明日方舟：終末地》於 2026-01-22 11:00 公測，平台為 PC（GRYPHLINK 啟動器與 Epic Games Store）、PlayStation 5、iOS 與 Android。GeForce NOW 於 2026-04-03 加入，Steam 則隨 2026-10-15 的 1.6 版更新上線。只要在同一個伺服器遊玩，所有平台的進度都互通。

## 平台與商店

| 平台 | 用戶端或商店 | 開放時間 | 登入方式 |
| --- | --- | --- | --- |
| PC（Windows） | GRYPHLINK 啟動器，從官網下載 | 公測，2026-01-22 | Gryphline 帳號 |
| PC（Windows） | Epic Games Store | 公測，2026-01-22 | Gryphline 帳號 |
| PlayStation 5 | PlayStation Store | 公測，2026-01-22 | 僅限 PSN 帳號 |
| iOS 與 iPadOS | App Store | 公測，2026-01-22 | Gryphline 帳號 |
| Android | Android 用戶端 | 公測，2026-01-22 | Gryphline 帳號 |
| PC（Windows） | Steam，app 4732690 | 1.6 版更新後，2026-10-15 | 與 Gryphline 帳號綁定的 Steam 帳號 |
| 雲端 | NVIDIA GeForce NOW：Windows PC、Mac、Chromebook 上的用戶端，或 Chrome、Edge 中的網頁版 | 2026-04-03 | Gryphline 帳號 |

- Gryphline 帳號可透過 Google、Apple、Facebook 等第三方帳號登入。
- 每個平台都能進入兩個伺服器。GeForce NOW 需要 GeForce NOW 會員資格，是否可用取決於所在國家或地區。
- Steam 版與其他平台共用遊戲伺服器，只能透過 Steam 用戶端下載與更新，無法透過 GRYPHLINK。遊戲內購買經由 Steam 內嵌介面（Steam Overlay）完成。

## PC 配備需求

| 項目 | 最低配備 | 建議配備 |
| --- | --- | --- |
| 作業系統 | Windows 10 64-bit 或 Windows 11 64-bit，DirectX 11.1 及以上 | 相同 |
| 處理器 | Intel Core i5-9400F 或同等級 | Intel Core i7-10700K 同等級及以上 |
| 顯示卡 | NVIDIA GeForce GTX 1060 或同等級 | NVIDIA GeForce RTX 2060 同等級及以上，驅動程式升級到最新版本 |
| 記憶體 | 16 GB | 16 GB 及以上 |
| 儲存空間 | 預留 50 GB，解壓縮時另需 40 GB；建議安裝在固態硬碟 | 相同 |

## PC、PlayStation 5 與手機的進度互通嗎？

在同一個伺服器內互通。Asia 伺服器與 Americas / Europe 伺服器之間的帳號資料一律不互通（[伺服器與時間](/zh-tw/systems/servers-and-time/)）。在某個平台購買的道具，以同一個 Gryphline 帳號登入其他平台也能使用。

| 平台 | 如何共用進度 |
| --- | --- |
| PC、Android、iOS、GeForce NOW | 以同一個 Gryphline 帳號登入，並選擇角色所在的伺服器 |
| Steam | 首次啟動時選擇「登入已有信箱帳號並綁定」，輸入原有 Gryphline 帳號的信箱。選擇「註冊並綁定」則會建立新帳號 |
| PlayStation 5 | 將 PSN 帳號與 Gryphline 帳號綁定；伺服器依 PSN 帳戶所在地區決定 |

## 可以用控制器嗎？

可以。PC 與行動裝置支援以下控制器；使用第三方品牌控制器可能有相容性問題。

| 控制器 | PC 藍牙連接 | 行動裝置藍牙連接 |
| --- | --- | --- |
| DualSense、DualSense Edge（PS5）、DUALSHOCK 4（PS4） | 僅支援自適應扳機；不支援震動與控制器揚聲器 | 與 PC 相同 |
| Xbox 無線控制器、Xbox Elite 無線控制器 | 完整功能 | 不支援震動與自適應扳機 |

- 行動裝置上的 Xbox 控制器，繁體中文的控制器常見問題寫不支援自適應扳機，英文的常見問題寫的是 impulse trigger（脈衝扳機）。
- 兩類控制器都可用 USB 有線或藍牙連接。在 PlayStation 5 以外的平台，以有線連接才有 PlayStation 控制器的完整功能。
- 在登入介面進行任意控制器操作，即切換至控制器介面。遊戲中按下控制器按鍵會跳出切換提示；按下鍵盤按鍵或點擊觸控螢幕，則跳出切換回原操作模式的提示。
- 管理員角色選擇與命名頁面、教學引導、角色對話與劇情演出，以及部分戰鬥場景與模擬空間中無法切換操作模式。
- 文字輸入：PC 使用鍵盤，行動裝置與 PlayStation 使用系統的虛擬鍵盤。
- 震動與自適應扳機在「設定」→「操控」中開關，控制器揚聲器在「設定」→「音訊」中設定。
- 1.2 版在「設定 - 控制器」中新增自訂按鈕設定。

## PSN 帳號與 Gryphline 帳號綁定

| 情況 | 可行的做法 |
| --- | --- |
| 從未登入過遊戲的 PSN 帳號 | 首次登入並同意使用者協議後，綁定視窗可綁定已有 Gryphline 帳號的信箱。跳過視窗會建立新的 Gryphline 帳號，視窗也不會再出現 |
| 已有遊戲進度的 PSN 帳號 | 「設定」→「平台與帳戶」→「帳戶中心」→「綁定信箱」，綁定未註冊為 Gryphline 帳號的信箱 |
| 解除綁定 | 在 Gryphline 帳號的帳戶中心，每個帳號限一次 |
| 限制 | 一個 PSN 帳號只能綁定一個 Gryphline 帳號，一個 Gryphline 帳號信箱也只能綁定一個 PSN 帳號 |

- 綁定後，PlayStation 5 仍只能用 PSN 帳號登入，PC 與行動裝置仍只能用 Gryphline 帳號登入。
- 在其他平台取得的進度，會在下次登入 PlayStation 5 時解鎖對應的獎盃。
- PlayStation 5 上有兩個好友列表：「明日方舟：終末地的好友」在任意平台可見，「PlayStation™Network的好友」只在 PlayStation 5 上可見。

## Steam

| 階段 | 內容 |
| --- | --- |
| 「先鋒測試」 | 正式上線前、名額有限的測試，使用線上正式伺服器，開放付費且不刪檔 |
| 正式上線 | 2026-10-15 的 1.6 版更新後，支援兩個伺服器。「先鋒測試」期間的進度與購買都保留 |

- 只以 Google、Apple 或 Facebook 登入過的 Gryphline 帳號，要先在 Gryphline 通行證帳戶中心綁定信箱，才能與 Steam 連結。
- Steam 帳號可在遊戲內「設定」→「平台與帳戶」→「帳戶中心」解除連結，也可在 Gryphline 通行證帳戶中心網站解除。

## 更新遊戲

1.4 版整合並優化資源，使行動裝置用戶端變小。

| 平台 | 更新方式 |
| --- | --- |
| PC，GRYPHLINK | 關閉遊戲，重新啟動 GRYPHLINK 並點擊更新 |
| PC，Steam | 在 Steam 收藏庫下載新版本 |
| Android | 依照遊戲內彈出視窗提示 |
| iOS | 在 App Store 點擊更新 |
| PlayStation 5 | 在系統介面選擇遊戲，按「選項（OPTIONS）」按鈕，再選「檢查更新」 |

## NVIDIA 顯示卡的已知問題

| 起始 | 問題 | 解決方式 |
| --- | --- | --- |
| 2026-02-07 | NVIDIA App 的優化功能可能導致畫面模糊與卡頓 | 在 NVIDIA App 的圖形 → 程式設定中選擇遊戲並恢復為未優化，關閉新遊戲的自動優化；或在遊戲內調低 DLSS 模式或畫質 |
| 2026-03-17 | GeForce Game Ready 驅動程式 595.79、595.71 與 NVIDIA Studio 驅動程式 595.79 可能導致卡頓 | 在 GRYPHLINK 勾選 DirectX 11 啟動，或在 NVIDIA App 重新安裝舊版驅動程式 |

## 啟動器與輔助工具

- GRYPHLINK 啟動器有遊戲即時數據面板（2026-07-10 新增）：以 Gryphline 帳號登入後，點擊「查看角色看板」可在遊戲離線時查看理智、日常活躍度與每週事務，並在帳號下的角色之間切換。
- 遊戲工具從遊戲內的「協議同步器」進入，提供 WIKI、地圖工具、「協議終端」與陣容分享。

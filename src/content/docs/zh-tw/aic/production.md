生產設備依配方把原料加工成產物。每台設備同時只能生產一種配方，只要放入的物品符合任一配方，就會立刻開始生產。物品由傳送帶從其他設備或倉庫送入，液體走管道；產物再經傳送帶送往下一台設備、倉庫存貨口或協議儲存箱。

## 設備如何輸入與輸出

- 協議核心、次級核心與大部分生產設備都有輸入口與取貨口。從取貨口連出的傳送帶把物品送出；連入輸入口的傳送帶把物品送入。
- 協議核心與次級核心的連接口和地區倉庫相連：在取貨口選定物品後，它就會從倉庫送出該物品。其他設備的連接口只連到設備自己的儲存。
- 也可以把背包或倉庫中的物品手動拖入設備，再把產物收回。
- 設備介面左側是輸入口與傳送帶送入的材料，右側是取貨口與送出的產物。
- 設備阻塞時，會停止輸入與輸出，介面下方出現阻塞警示。
- 武陵有些設備具有液體模式，多出可接管道的液體連接口；切換模式會改變設備可用的配方。自 1.4 版起，可在擺放前先選好模式。

## 物流設備

| 設備 | 作用 | 限制 |
| --- | --- | --- |
| 傳送帶 | 在設備之間運輸物品 | 只限集成核心區域；起點必須是設備或已擺放的傳送帶 |
| 物流橋 | 讓兩條相交的傳送帶各自運輸、互不影響 | |
| 分流器 | 把一條傳送帶平均分成最多三條 | |
| 匯流器 | 把最多三條傳送帶合併為一條 | |
| 管道 | 在液體連接口之間輸送液體 | 單次擺放有長度上限；末端自動生成的管道支架可接續下一段 |
| 暗管入口與暗管出口 | 成對連接，經地下輸送液體 | 1.4 版起按直線距離計算，上限 300m（原為 200m） |
| 倉庫存取線源樁與倉庫存取線基段 | 組成倉庫存取線：源樁是起點，基段向外延伸 | 源樁可擺在集成核心區域任意位置；基段須連接源樁或已啟用的基段 |
| 倉庫取貨口 | 把選定的倉庫物品送上傳送帶 | 須貼靠倉庫存取線擺放 |
| 倉庫存貨口 | 把傳送帶送來的物品存入倉庫 | 須貼靠倉庫存取線擺放 |
| 協議儲存箱 | 存放物品，接入電網且電力充足時把物品傳送至倉庫，常放在產線末端 | 用電 5 |
| 儲液罐與儲氣罐 | 儲存液體與氣體 | |

## 協議容量

每個地區都有獨立的協議容量上限。在集成核心區域外擺放設備會消耗協議容量，不同設備消耗的量不同；某地區的協議容量用完後，該地區就無法再擺放新設備。地區建設等級提升會提高這些上限：見[地區建設](/zh-tw/aic/regional-development/)。

## 擴容反應池：自動處理多個配方阻塞

自 1.3 版起，擴容反應池在進行多個配方反應時，若這些配方都處於阻塞狀態，會自動清空暫存區內的全部物品，讓反應繼續進行。此選項預設開啟，且選項狀態會隨藍圖儲存。

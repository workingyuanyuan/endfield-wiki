集成工業系統（AIC）是《明日方舟：終末地》的工廠系統：在野外擺放設備，自動開採礦物、精煉與封裝，並由地區電網供電；產物是製造裝備、戰術物品、工業設備與交易貨品的材料。四號谷地與武陵各有一套集成工業系統，中心是一座協議核心，兩個地區的電網、倉庫與擺放上限互相獨立。

## 核心設備

| 設備 | 作用 |
| --- | --- |
| 協議核心 | 地區集成工業的中樞，也是地區電網唯一的電力來源、協議傳送點，以及開啟協議管理（跨地區傳輸）之處。它的輸入口與取貨口和地區倉庫相連。 |
| 集成核心區域 | 協議核心或次級核心周圍的區域。擺在這裡的供電樁會自動接入電網，傳送帶只能建在這裡；在這裡和協議傳送點附近，背包與倉庫相通。 |
| 次級核心 | 功能與協議核心類似的次要核心，在自己的集成核心區域內作為協議傳送點、提供倉庫的取貨口，並自動為區域內的供電樁供電。每個據點有一座次級核心，次級核心必須與主協議核心有電力連接才能運作。 |
| 集成管家 | 位於集成核心區域旁；在此消耗地區調度券升級，區域面積會擴大。 |
| 工業發展規劃 | 工業技術的研究樹，共分三期；推進主線任務取得拓展核心後，才能開啟下一期。 |

協議核心與次級核心不能自行擺放，只能移動，所以藍圖不會包含它們。

## 有集成工業系統的地區

| 地區 | 以地區命名的電池 | 據點 |
| --- | --- | --- |
| 四號谷地 | 低容量、中容量、高容量谷地電池 | 3 |
| 武陵 | 低容量、中容量武陵電池 | 3：天王坪援助點、心臟修繕站（1.2 版）、盈天台建設站（1.4 版） |

每個地區有自己的倉庫，在某地區探索時只能存取該地區的倉庫；在帝江號上可以手動切換要管理的地區倉庫。自 1.4 版起，進入武陵並擺放協議核心後，會先行解鎖並提供一批集成工業設備；這些設備要完成基礎工業計劃中對應工業技術的研究後，才能在四號谷地使用。

## 各版本的集成工業變更

| 版本 | 集成工業變更 |
| --- | --- |
| 1.1 | 開放武陵工業二期：水驅礦機、暗管入口與暗管出口、赤銅礦。設備可在地圖任意位置以材料製造，無需返回集成核心區域。電線保持不斷開的距離延長（見[集成工業電力](/zh-tw/aic/power/)）。 |
| 1.2 | 開放武陵工業三期：二型耐酸水泵、多口暗管入口與多口暗管出口、提純機、擴容反應池。新增據點心臟修繕站。 |
| 1.3 | 新增備用電源；地區建設介面新增事務總覽；擴容反應池新增自動處理多個配方阻塞；集成核心區域內的息壤供電樁與息壤中繼器可與外部息壤電力設備連接。 |
| 1.4 | 武陵新增氣體相關工業模式與氣體設備；新增據點盈天台建設站；野外設備可從地圖遠端收回至倉庫；暗管連接距離上限提升至 300m。 |
| 1.5 | 新增連續擺放；框選新建藍圖時即時顯示藍圖可儲存的設備數量上限。 |
| 1.6 | 新增自動農植機，用於祀的畫的種植區，之後也可用於武陵城的種植區。背包或任意倉庫中已有設備，或倉庫內材料足以製造時，可直接擺放設備。 |

1.1 至 1.6 版每一版也都提升了武陵的地區建設等級上限。各版本的標題與日期：[1.1](/zh-tw/versions/1-1/)、[1.2](/zh-tw/versions/1-2/)、[1.3](/zh-tw/versions/1-3/)、[1.4](/zh-tw/versions/1-4/)、[1.5](/zh-tw/versions/1-5/)、[1.6](/zh-tw/versions/1-6/)。

## 藍圖分享規範

分享藍圖分享碼，就是允許任何人查看、複製與使用該設計。在集成工業系統中發布涉及歧視、誹謗、淫穢、暴力、賭博、仇恨或其他服務條款禁止的內容，可能導致擺放物被移除、集成工業功能受限或帳號停權。

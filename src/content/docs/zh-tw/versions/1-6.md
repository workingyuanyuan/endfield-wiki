## 更新維護

1.6 版是[公測](/zh-tw/versions/1-0/)後的第六次更新，遊戲也在這個版本登陸 Steam。更新維護於當日 06:00 至 12:00 進行。

## 新增內容

| 類別 | 新增 |
| --- | --- |
| 主線任務 | 開放至「第二章 - 進度VIII - 著新墨」 |
| 探索任務 | 奇聞滿地跑、後目的地、開畫大吉、農植自動化改造 |
| 支線任務 | 歸野、無終之戀、前緣再續、紀念日、緣緣莊經營·其一至其三 |
| 區域 | 武陵 - 祀的畫 |
| 幹員 | [祀](/zh-tw/operators/si/)與[明河](/zh-tw/operators/argent-flow/)，皆為 6 星 |
| 6 星武器 | 玉中身（雙手劍）、喚月（單手劍）、悠久傳承（雙手劍）、聚合工業（單手劍） |
| 敵人 | 存祿、用奇、解燥、行度等 |
| 集成工業設備 | 自動農植機，用於「祀的畫」的種植區，之後也可用於「武陵城」的種植區 |
| 玩法 | 緣緣莊客棧，沒有經營任務 |

## 系統變更

- 戰鬥：可在編隊介面設定連攜技的優先順序，並新增第六、第七小隊。
- 裝備方案：可儲存多套裝備配置、自訂命名並切換。
- 有時效的理智藥劑到期時自動轉化為理智；超出理智上限的部分，在有理智萃取器時轉化為理智精粹藥劑，否則銷毀。
- 艙室小組：每個艙室可設定 A、B 兩個小組，手動啟用或自動輪換。
- 集成工業：「武陵」地區建設等級上限提升；設備可直接從背包或任意倉庫擺放。
- 湯湯終結技的描述改寫為施加定身，實際效果不變。
- 平台：新增 Steam 用戶端，帳號與伺服器相同。

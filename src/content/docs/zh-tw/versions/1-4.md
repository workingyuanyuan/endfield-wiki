1.4 版「向淵行」是公測後的第四次更新，屬於核心章節版本，更新維護於 2026-07-16 06:00 至 12:00 進行。從這個版本起，管理員完成「第一章 - 進度II - 修繕進展」後即可接取武陵的第二章主線任務，不必先完成第一章。

## 新增內容

| 類別 | 新增 |
| --- | --- |
| 主線任務 | 開放至「第二章 - 進度VII - 餘暉未卻」 |
| 區域 | 武陵 - 應龍關、武陵 - 北部禁區 |
| 幹員 | [訣](/zh-tw/operators/arcane/)與[梨諾](/zh-tw/operators/liino/)，皆為 6 星 |
| 6 星武器 | 四二式·肅陣（施術單元）、曜夜的首演（長柄武器）、遙望（單手劍）、聯結點（施術單元）、黃金時代（長柄武器） |
| 敵人 | 「阿萊克琉斯，千夫長」與 8 種蝕影敵人，其中有蝕影應龍隊長 |
| 集成工業 | 武陵的氣體工業（氣體收集、氣體反應爐等工業規劃）、氣體「惰氣」與「息壤氣」、據點「盈天台建設站」 |
| 裝備套裝 | 集成實訓、涉淵 |
| 材料 | 塔羅斯菌（晉升）、紅矛葉（技能專精）、協議紋石（武器突破） |

## 系統變更

- 提前前往武陵：武陵大部分敵人的等級隨探索等級變化；在武陵擺放協議核心後會先解鎖一批集成工業設備，這些設備要在完成對應工業技術研究後才能在四號谷地使用。
- 戰鬥：可設定隊友技能特效的品質與不透明度；索敵分為三項獨立設定（技能優先攻擊目標、主動鎖定目標、輔助選擇目標）。
- 新功能：塔晶集換（在應龍關與北部禁區收集塔晶）、材料轉化（在簡易製作中把高等級材料轉為低等級材料）、生日、ID資訊更新卡（每半年免費一張）、查看已擁有幹員的 2D 立繪。
- 幹員試用活動的獎勵新增武庫防具箱，內含適合該試用幹員的滿精鍛 60 級套裝裝備。
- 集成工業：「武陵」地區建設等級上限提升；暗管連接距離改以直線計算，上限由 200 m 提高到 300 m；協議核心區域以外的設備可從地圖直接收回；金色品質裝備可切換製造工藝，使用最新工藝時調度券消耗減少 99%。
- 裝飾物品不再占用背包與倉庫容量。尋訪紀錄與申領紀錄保留 90 日內的特許尋訪與武庫申領獎勵紀錄。
- O.M.V.帝江號：會客室線索交流由 24 小時縮短為 20 小時，艙室可從總控中樞遠端升級。
- 畫面：PC 支援 NVIDIA DLSS 4.5 超解析度與 AMD FSR 3，PlayStation 5 Pro 支援升級版 PSSR。
- 修復：[阿列什](/zh-tw/operators/alesh/)解鎖潛能「鹹鱗翻身」後，施放戰技無法觸發部分武器技能效果。
- 修復：[晝雪](/zh-tw/operators/snowshine/)為主控幹員時，特定操作後畫面異常轉動；[卡契爾](/zh-tw/operators/catcher/)在隊伍中施放重擊時畫面抖動；行動裝置上[莊方宜](/zh-tw/operators/zhuang-fangyi/)的下墜攻擊沒有震動回饋；卡繆的翅膀在介面轉場時顯示異常。
- 弭弗的連攜技音效經過優化。

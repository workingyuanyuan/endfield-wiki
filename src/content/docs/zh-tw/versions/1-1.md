1.1 版「新潮起，故淵離」是[公測](/zh-tw/versions/1-0/)後的第一次更新，更新維護於 2026-03-12 06:00 至 12:00 進行。這個版本開放了武陵的新區域清波寨。

| 類別 | 新增 |
| --- | --- |
| 主線任務 | 開放至「第二章 - 進度III - 共飲一江水」 |
| 探索任務 | 「據點建設·天王坪援助點·二」、「侵蝕中的呼救」 |
| 支線任務 | 「奪寶奇兵·其一」至「奪寶奇兵·其三」、「泉中客·其一」至「泉中客·其三」、「紅騎士」 |

| 6 星武器 | 落草（手銃）、望鄉（手銃）、狼之緋（單手劍）、光榮記憶（單手劍） |
| 敵人 | 莫惜命、過堂風、劫雲客、割雲翁、斷雲叟、摧山將、開天將等 |
| 集成工業計劃 | 武陵工業二期：洪爐擴容II、水輔礦物採掘、暗管、廢水處理、液輔熔煉、AF1「熔甲者」、激流塔 |
| 集成工業設備 | 水驅礦機、暗管入口、暗管出口、AF1「熔甲者」、激流塔；礦點赤銅礦 |
| 新手任務 | 「新手特許贈禮」，常駐，可得特許尋訪憑證 ×10 |

## 系統變更

- 集成工業：可在地圖上任意位置消耗攜帶的材料製造設備，無需返回集成核心區域。
- 集成工業：可在地圖介面直接刪除他人留下的共享設備，共享滑索與自建滑索的樣式有所區分；登上滑索架、開始滑動前顯示小地圖。
- 集成工業：電線保持不斷開的距離延長，中繼器由 90m 提升至 100m，供電樁由 40m 提升至 50m；電路連接距離不變。
- 集成工業：俯瞰模式的可見範圍擴大；PC 版可設定按 ESC 鍵關閉俯瞰模式，並可長按滑鼠左鍵移動多個已選取的設備；控制器模式新增「移動」選項。
- 地區建設：「武陵」地區建設等級上限，以及物資調度、倉儲節點、環境監測與「天王坪援助點」據點的等級上限提升。「四號谷地 - 礦脈源區」的物資調度升至 4 級後，谷地多痕刻寫箱可得一個包含三條自訂屬性的基質。
- 挑戰幹員養成、武器養成、危境再現與危境預演相關的協議空間時，小隊以獨立的滿生命值、滿終結技能量狀態進入戰鬥，與外部狀態互不影響。
- 未及時拾取的稀有植物、稀有礦物與部分協議空間的材料，會自動送往信箱暫存區。
- 十個裝備套裝新增部分裝備部件，包括 50式應龍裝備組、點劍裝備組與紓難裝備組。所有幹員新增切換時的語音與受擊時的表情反應。
- 設定：「控制」新增鏡頭距離，「效能與畫面」新增顯示模式。
- 伊馮終結技的描述改寫，實際效果不變。[安塔爾](/zh-tw/operators/antal/)的中文配音演員姓名更新。4 星武器「緊急手段」更名為「顯鋒」。
- 萊萬汀的修復：強化戰技的追加攻擊瞬間衝刺，或以該追加攻擊擊敗處於灼熱附著狀態的敵人時，熔火層數異常；終結技即將結束時施放戰技，終結技提前結束。
- 其他幹員的修復：伊馮無法處決敵人；別禮的連攜技無法凝結敵人；餘燼施放戰技期間受到多段攻擊時表現異常，第三段普通攻擊會失去目標；[大潘](/zh-tw/operators/da-pan/)的終結技與連攜技失去目標；[艾維文娜](/zh-tw/operators/avywenna/)的潛能「恩威並施」改為與描述一致，「籌碼加倍」不再異常生效。
- 平台：這個版本期間起可在 NVIDIA GeForce NOW 遊玩，同一伺服器內進度與其他平台互通。

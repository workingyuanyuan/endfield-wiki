1.5 版「雪淞幽夢」是公測後的第五次更新，更新維護於 2026-09-02 06:00 至 12:00 進行。這個版本開放了武陵的兩個新區域，並推出首期重構尋訪與重構申領，這兩種類型各有自己的保底規則。

## 新增內容

| 類別 | 新增 |
| --- | --- |
| 支線任務 | 霧隱冬夢深林中、終其一生、命運的明示 |
| 區域 | 武陵 - 雪松林、武陵 - 遂明 |
| 幹員 | [提弗洛斯](/zh-tw/operators/typhoeus/)（6 星）、[噗切娜](/zh-tw/operators/purrchena/)（5 星） |
| 6 星武器 | 寒夜幽影（施術單元）、苦難的盡頭（施術單元） |
| 5 星武器 | 點心時刻（單手劍） |
| 敵人 | 蟲體樹傀、徘徊樹傀、幽林之怒 |
| 裝備套裝 | 險關 |
| 訓練關卡 | 提弗洛斯的靶場，附模擬訓練首通獎勵 |

噗切娜透過活動「我們的大菲林！來襲！」免費取得，不在任何尋訪中。

各尋訪可能出現的 6 星幹員：

| 尋訪 | 可能出現的 6 星幹員 |
| --- | --- |
| 冬獵 | 提弗洛斯、[梨諾](/zh-tw/operators/liino/)、[訣](/zh-tw/operators/arcane/)、[餘燼](/zh-tw/operators/ember/)、[黎風](/zh-tw/operators/lifeng/)、[艾爾黛拉](/zh-tw/operators/ardelia/)、[別禮](/zh-tw/operators/last-rite/)、[駿衛](/zh-tw/operators/pogranichnik/) |
| 絢麗異彩 | 伊馮、餘燼、黎風、艾爾黛拉、別禮、駿衛 |

「冬獵」是這個版本唯一的特許尋訪。[卡繆](/zh-tw/operators/camille/)在 [1.4 版](/zh-tw/versions/1-4/)最後一期的名單內，卻不在「冬獵」的名單內：機率提升的幹員在 3 次特許尋訪後移出特許尋訪名單，也不會加入基礎尋訪。另見[尋訪機率與保底](/zh-tw/systems/headhunting/)。

兩種重構類型的規則：

- 「絢麗異彩」：前 120 次尋訪必定獲得伊馮。累計尋訪 30、60、90 次時各得一次加急招募（免費十連），每累計 240 次得伊馮的信物 ×1。這些計數都繼承到後續的「絢麗異彩」，其中保底與加急招募在所有「絢麗異彩」中只生效 1 次。
- 「點繪申領」：連續 3 次申領沒有 6 星武器時，第 4 次必定獲得，這個計數只在重構申領#1 內有效。若前 7 次申領都沒有藝術暴君，第 8 次必定獲得，這個計數繼承到後續的「點繪申領」，且只生效 1 次。
- 特許尋訪憑證除了特許尋訪，也可用於重構尋訪。

## 系統變更

- 培養總覽（位於幹員介面）：統一查看已持有、未持有及前瞻的幹員與武器，各培養目標所需的資源，以及已持有的數量。
- 集成工業：「武陵」地區建設等級上限與據點「盈天台建設站」等級上限提升；開啟連續擺放後，擺放設備、裝飾物品或田塊時不會退出建造狀態。
- 劇情對話可隱藏介面，也可與自動播放同時使用。部分關卡結算介面顯示通關耗時。
- 會客室：快速填入會自動填入所有可填入的線索，快速贈予重複線索可一鍵把多餘線索送給好友。
- 幹員信賴值已滿時，送禮仍計入送禮相關任務。
- 修復：訣處於「陣訣·智」形態時，特定操作可能使戰技的技力返還與傷害異常。
- 修復：梨諾的戰技初次命中敵人時，打斷敵人蓄力狀態的次數異常。
- 修復：「向淵行」版本更新後，攜帶回復終結技能量的戰術物品進入部分關卡時，可能異常消耗這些物品。
- [洛西](/zh-tw/operators/rossi/)戰技描述中一項屬性提升的文字，以及[螢石](/zh-tw/operators/fluorite/)戰技描述中緩速的文字經過改寫，實際效果不變。
- 訣與梨諾部分動作的語音，以及[埃特拉](/zh-tw/operators/estella/)檔案中的部分語音經過優化。

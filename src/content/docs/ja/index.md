## プラットフォーム

PC（公式ランチャーとEpic Games Store）、PlayStation 5、iOS、Androidには2026-01-22 11:00の正式リリースから、Steamにはバージョン1.6アップデートの2026-10-15から対応している。1つのアカウントのセーブデータは、同じサーバー内でプラットフォーム間で共有される。AsiaサーバーとAmericas / Europeサーバーの間では共有されない。

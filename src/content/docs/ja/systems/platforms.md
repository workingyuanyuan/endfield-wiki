『アークナイツ：エンドフィールド』は2026-01-22 11:00にPC（GRYPHLINKランチャーおよびEpic Games Store）、PlayStation 5、iOS、Androidで正式リリースされた。2026-04-03にGeForce NOWに対応し、2026-10-15のバージョン1.6アップデートとともにSteam版が配信された。同じサーバーでプレイしていれば、すべてのプラットフォーム間で進行状況が共有される。

## プラットフォームとストア

| プラットフォーム | クライアントまたはストア | 対応開始 | ログイン方法 |
| --- | --- | --- | --- |
| PC（Windows） | GRYPHLINKランチャー（公式サイトから入手） | 正式リリース、2026-01-22 | Gryphlineアカウント |
| PC（Windows） | Epic Games Store | 正式リリース、2026-01-22 | Gryphlineアカウント |
| PlayStation 5 | PlayStation Store | 正式リリース、2026-01-22 | PSNアカウントのみ |
| iOSおよびiPadOS | App Store | 正式リリース、2026-01-22 | Gryphlineアカウント |
| Android | Androidクライアント | 正式リリース、2026-01-22 | Gryphlineアカウント |
| PC（Windows） | Steam（アプリID 4732690） | バージョン1.6アップデート後、2026-10-15 | Gryphlineアカウントと連携したSteamアカウント |
| クラウド | NVIDIA GeForce NOW：Windows PC、Mac、Chromebook用クライアント、またはChrome・Edgeのウェブ版 | 2026-04-03 | Gryphlineアカウント |

- Gryphlineアカウントは、Google、Apple、Facebookなどの外部アカウントを使ってログインできる。
- すべてのプラットフォームから両サーバーへ接続できる。GeForce NOWはGeForce NOW会員資格が必要で、利用可否は国や地域による。
- Steam版は他プラットフォームと同じサーバーで動作し、ダウンロードとアップデートはGRYPHLINKではなくSteamクライアント経由でのみ行う。購入はSteamオーバーレイを通じて行われる。

| 項目 | 必要動作環境 | 推奨動作環境 |
| --- | --- | --- |

## PC、PlayStation 5、モバイル間で進行状況は共有されるか

同一サーバー内であれば共有される。AsiaサーバーとAmericas / Europeサーバーのアカウントデータは共有されない（[サーバーと時間](/ja/systems/servers-and-time/)）。あるプラットフォームで購入したものは、同じGryphlineアカウントであれば他のプラットフォームでも利用できる。

| プラットフォーム | 進行状況を共有する方法 |
| --- | --- |
| PC、Android、iOS、GeForce NOW | 同じGryphlineアカウントでログインし、キャラクターがいるサーバーを選ぶ |
| Steam | 初回起動時に「既存のメールアドレスでログインして連携する」を選び、既存のGryphlineアカウントのメールアドレスを入力する。「登録して連携する」を選ぶと新規アカウントが作成される |
| PlayStation 5 | PSNアカウントをGryphlineアカウントに連携する。サーバーはPSNアカウントの地域に従う |

## コントローラーは使えるか

使える。PCとモバイル機器では以下のコントローラーに対応している。サードパーティ製コントローラーは互換性の問題が生じる場合がある。

| コントローラー | PCでのBluetooth接続 | モバイルでのBluetooth接続 |
| --- | --- | --- |
| DualSense、DualSense Edge（PS5）、DUALSHOCK 4（PS4） | アダプティブトリガーのみ対応。振動とコントローラースピーカーは非対応 | PCと同じ |
| Xbox ワイヤレスコントローラー、Xbox Elite ワイヤレスコントローラー | 全機能に対応 | 振動とインパルストリガーは非対応 |

- モバイルでのXboxコントローラーについて、英語版のコントローラーFAQではインパルストリガー（impulse triggers）、繁体字中国語版のFAQではアダプティブトリガーと呼んでいる。
- どちらもUSBケーブルまたはBluetoothで接続できる。PlayStation 5以外のプラットフォームでも、有線接続すればPlayStationコントローラーの全機能が使える。
- ログイン画面で何らかのコントローラー操作を行うとコントローラーレイアウトに切り替わる。プレイ中はボタンを押すと切り替え確認が表示され、キーボード入力や画面タップで元の操作へ戻す確認が表示される。
- オペレーター選択・名前作成画面、チュートリアル、会話やストーリー演出中、一部の戦闘や模擬空間ではレイアウトを切り替えられない。
- 文字入力はPCではキーボード、モバイルとPlayStationではシステムの仮想キーボードで行う。
- 振動とアダプティブトリガーは「設定」→「コントローラー」で、コントローラースピーカーは「設定」→「サウンド」で切り替える。
- バージョン1.2で「設定」→「コントローラー」にボタンのカスタム設定が追加された。

## PSNアカウントとGryphlineアカウントの連携

| 状況 | 連携方法 |
| --- | --- |
| ゲームにログインしたことがないPSNアカウント | 初回ログイン時、利用規約に同意した後のポップアップで既存Gryphlineアカウントのメールアドレスを連携する。スキップすると新しいGryphlineアカウントが作られ、ポップアップは二度と表示されない |
| すでに進行状況があるPSNアカウント | 「設定」→「外部サイトとアカウント」→「アカウント」→「メールアドレス連携」から、Gryphlineアカウントに登録されていないメールアドレスを連携する |
| 連携解除 | Gryphlineアカウントのアカウントセンターで、1アカウントにつき1回のみ可能 |
| 制限 | 1つのPSNアカウントは1つのGryphlineアカウントとのみ、1つのGryphlineアカウントのメールアドレスは1つのPSNアカウントとのみ連携できる |

- 連携後も、PlayStation 5ではPSNアカウントでのみ、PCとモバイルではGryphlineアカウントでのみログインできる。
- 他プラットフォームで達成した進行状況に対応するPlayStationトロフィーは、次回PlayStation 5でログインした際に解放される。
- PlayStation 5では「アークナイツ：エンドフィールドフレンド」（全プラットフォームで表示）と「PlayStation Networkフレンド」（PlayStation 5でのみ表示）の2つのフレンド一覧が表示される。

## Steam

| 段階 | 内容 |
| --- | --- |
| 「パイオニアテスト」 | 正式配信前に人数限定で実施されたテスト。正式サーバーを使用し、課金あり・データ引き継ぎあり |
| 正式配信 | 2026-10-15のバージョン1.6アップデート後、両サーバーで開始。「パイオニアテスト」の進行状況と購入履歴は引き継がれた |

- Google、Apple、FacebookのみでログインしていたGryphlineアカウントは、Steamと連携する前にGryphlineアカウントセンターでメールアドレスを登録しておく必要がある。
- Steamの連携解除は、ゲーム内の「設定」→「外部サイトとアカウント」→「アカウント」、またはGryphlineアカウントセンターのウェブサイトから行える。

## ゲームのアップデート方法

バージョン1.4でリソースが統合され、モバイルクライアントの容量が削減された。

| プラットフォーム | アップデート手順 |
| --- | --- |
| PC、GRYPHLINK | ゲームを終了し、GRYPHLINKを再起動してアップデートをクリックする |
| PC、Steam | Steamライブラリから新バージョンをダウンロードする |
| Android | ゲーム内の案内表示に従う |
| iOS | App Storeでアップデートする |
| PlayStation 5 | ホーム画面でゲームを選び、OPTIONSボタンを押して「アップデートを確認する」を選ぶ |

## NVIDIAグラフィックボードの既知の不具合

| 確認日 | 不具合 | 対処法 |
| --- | --- | --- |
| 2026-02-07 | NVIDIA Appの最適化により画面がぼやけたりカクついたりする場合がある | NVIDIA Appで「グラフィックス」→「プログラム設定」→ゲームを選択→元に戻し、新しいゲームの自動最適化をオフにする。またはゲーム内でDLSSモードやグラフィック設定を下げる |
| 2026-03-17 | GeForce Game Readyドライバー595.79および595.71と、NVIDIA Studioドライバー595.79でカクつきが発生する場合がある | GRYPHLINKで「DirectX 11で起動」にチェックを入れるか、NVIDIA Appで旧バージョンのドライバーを再インストールする |

## ランチャーと補助ツール

- GRYPHLINKランチャーにはリアルタイムデータボードがある（2026-07-10追加）。Gryphlineアカウントでログインしたあと「ゲームデータ表示」を開くと、ゲームを起動していない状態でも理性、デイリー活躍度、ウィークリークエストを確認でき、アカウント内のキャラクター切り替えも行える。
- ゲーム内の「協約同期装置」から開くゲームツールでは、Wiki、マップツール、「協約ターミナル」、共有されたおすすめ編成を利用できる。

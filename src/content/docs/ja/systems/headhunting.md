スカウトはオペレーターを入手する手段である。1回あたりの星6オペレーターの基礎確率は0.8%で、カウント対象の80回以内に星6が確定する（緊急招集はカウントされない）。特別スカウトではピックアップ対象の星6オペレーターが1名設定され、そのスカウトの最初の120回以内に確定する。この120回のカウントは次のスカウトへ引き継がれないが、80回のカウントは引き継がれる。ピックアップ対象のオペレーターは自身を含めて3回の特別スカウトの排出枠に留まり、通常スカウトには追加されない。バージョン1.6までに、過去のピックアップ対象2名が再現スカウト#1で再登場した（バージョン1.5のイヴォンヌ、バージョン1.6のタンタン）。再現スカウトの120回ピックアップ確定は同名の全開催を通して1回のみ適用され、カウントは同名開催間で引き継がれる。レーヴァテインとギルベルタは特殊スカウト「輝きの祝典」でのみ再登場した。

## スカウト（ガチャ）の種類

| 種類 | 開催期間 | 内容 | 消費アイテム |
| --- | --- | --- | --- |
| 通常スカウト | 常設 | 通常ラインナップ、ピックアップなし | 通常スカウト券 |
| 特別スカウト（ピックアップガチャ） | 1回ずつ開催、「灼熱焔痕」から「万象一新」までは1回あたり約16〜35日間 | ピックアップ星6オペレーター1名。星6排出枠は8名 | 該当スカウト専用スカウト券、特別スカウト券、赤晶玉 |
| 再現スカウト（復刻ガチャ） | 名称ごとに番号付き（#1、#2）。バージョン1.5以降 | 過去のピックアップオペレーターが再登場。星6排出枠は6名 | 特別スカウト券、赤晶玉 |
| 特殊スカウト | 「輝きの祝典」、バージョン1.2 | ピックアップなし。星6オペレーター4名と、累計120回でその中から1名指名可能 | 「輝きの瞬間」スカウト券、特別スカウト券、赤晶玉 |
| 旅立ちスカウト | 各新規アカウントで40回を引き切り星6武器を選択するまで | 40回以内に通常ラインナップの星6オペレーター1名と星6武器選択箱 | 初心者マイルストーンで得られるスカウト券 |

特別スカウト、再現スカウト、特殊スカウトは、メイン任務第一章プロセスⅠ「基地救援」を完了すると解放される。特別スカウト券はバージョン1.5以降、再現スカウトでも使用できる。メイン任務第一章プロセスⅠ「基地救援」を完了したアカウントには、通常スカウトの星6オペレーターを1名選んで入手できる指名招集券が配布される（初回配布は2026-02-05のアップデート後）。バージョン1.1で追加された常設イベント「旅立ち特別スカウト特典」では、第一章の進行に応じて特別スカウト券×10を獲得できる。

## 確率と天井（確定・ピックアップ）

| ルール | 値 |
| --- | --- |
| 基礎確率 | 星6 0.8%、星5 8.0%、星4 91.2% |
| 星5以上 | 10回以内に確定 |
| いずれかの星6（天井） | 80回以内に確定 |
| 星6確率上昇（仮天井） | 星6が出ずに65回経過すると、1回ごとに+5パーセントポイント上昇（66回目で5.8%、67回目で10.8%） |
| ピックアップ割合（50/50） | 特別スカウトで通常排出される星6のうち、50%がピックアップ対象オペレーター |
| ピックアップ対象オペレーター | 最初の120回以内に確定（各特別スカウトで1回、同名の再現スカウト全体で1回） |
| 印 | 累計240回ごとに、ピックアップ対象オペレーターの印×1 |

10回確定、80回確定、確率上昇は通常スカウト、特別スカウト、再現スカウトに適用され、80回のカウントは種類ごとに保持される。通常スカウトにピックアップはない。特殊スカウト（「輝きの祝典」）は独立した10回・80回確定カウントを持っていた。その他のルールは下記の通りである。

## 星6すり抜けの確率

特別スカウトで通常排出される星6は、半分の確率でピックアップ対象オペレーターになる。残りの半分は排出枠にある他の星6オペレーター7名のいずれか（同枠内の他の限定オペレーター2名と恒常5名）である。したがって、過去のピックアップ対象オペレーターを特別スカウトで狙う場合、そのオペレーターが排出枠に残っている間にすり抜けで引くしかない。1つのスカウトでカウント対象の最初の119回にピックアップ対象が出なければ、120回目で確定する。この確定は1スカウトにつき1回のみで、それ以降のすり抜けを制限しない。

## 次のスカウトへの引き継ぎ

120回のピックアップ確定は、ある特別スカウトから次の特別スカウトへ引き継がれず、開催終了時にリセットされる。80回の星6カウントは、星6が出るまで同種の次のスカウトへ引き継がれる。

| カウントまたは報酬 | 特別スカウト | 再現スカウト | 特殊スカウト（「輝きの祝典」） |
| --- | --- | --- | --- |
| いずれかの星6（80回） | 星6が出るまで次の特別スカウトへ引き継ぎ | 名称を問わず全再現スカウトで共有。星6が出るまで引き継ぎ | 独立カウント。持ち込みも引き継ぎもなし |
| ピックアップ対象（120回） | 各スカウトの最初の120回。引き継ぎなし | 同名の全開催を通して1回のみ。カウントは同名開催へ引き継ぎ | ピックアップなし。累計120回で「輝きの瞬間」招集券（1回のみ） |
| 緊急招集 | 累計30回で無料10連1回。開催終了時に失効 | 累計30、60、90回で各1回（計3回）、同名全体で1回のみ。未使用分は同名開催へ引き継ぎ | 累計30回で無料10連1回。開催終了時に失効 |
| 累計60回 | スカウト情報ファイル（次の特別スカウトで使用） | 3回の緊急招集のうち2回目 | 通常スカウト券×10（1回のみ） |
| 累計240回 | ピックアップ対象オペレーターの印。スカウトごとにカウント | ピックアップ対象オペレーターの印。カウントは同名開催へ引き継ぎ | 「輝きの瞬間」印補給：所持済みの対象4名からいずれかの印を選択 |
| 報酬用の累計回数 | スカウトごとにカウント | 同名の再現スカウトへ引き継ぎ | 開催終了時に0へリセット |

## 再現スカウト（復刻）と特別スカウト（ピックアップ）の違い

- 排出枠：再現スカウトの星6枠は復刻オペレーターと恒常5名の計6名。特別スカウトは8名。
- 120回確定：特別スカウトは開催ごとにカウントされリセットされる。再現スカウトは同名の全開催を通して1回のみで、回数は同名の次回開催へ引き継がれる（同名の次回復刻は#2となり、#1のカウントをそのまま引き継ぐ）。
- 緊急招集：特別スカウトは30回で無料10連1回。同名の再現スカウトは30、60、90回で計3回与えられ、未使用分も引き継がれる。
- スカウト情報ファイル：特別スカウトでのみ入手できる。
- スカウト券：特別スカウト券と赤晶玉は両方で使える。特別スカウトでは該当スカウト専用スカウト券も使える。
- 特別スカウトの進捗への影響：なし。80回カウントは種類ごとに分かれているため、再現スカウトを引いても特別スカウトのカウントは進まず、逆も同様である。

## 復刻武器ガチャ（再現申請）

各再現スカウトには、同じ復刻に対応する武器ガチャの再現申請が併設され、同時に開始・終了する。これまで開催された2回の再現申請はいずれも、元の武庫申請と同じ星6武器7種（ピックアップ武器を含む）を再登場させた。通常の武庫申請との違いは引き継ぎルールにある。

| ルール | 武庫申請 | 再現申請 |
| --- | --- | --- |
| 連続3回星6武器が出なかった場合、4回目で確定 | あり | あり。ただし当期のみ有効で、同名の次回復刻には引き継がれない |
| 最初の7回でピックアップ武器が出なかった場合、8回目で確定 | 申請ごとに1回。終了時にリセット | 同名の全開催を通して1回。カウントは引き継ぎ |
| 累計申請報酬 | 終了時にカウントリセット | 同名の再現申請へカウントを引き継ぎ |

必要配給数、確率、各申請の一覧は[武庫申請と基質](/ja/systems/arsenal/)にある。

## 累計回数報酬

- 緊急招集：そのスカウトの基礎確率で引ける無料10連で、星5以上が確定する。天井カウントにも報酬用の累計回数にも加算されないため、緊急招集でピックアップ対象を引いても120回確定は消費されない。
- スカウト情報ファイル：特別スカウトで累計60回引くと貴重品倉庫に送られる。次の特別スカウトで10回スカウトでき、そのスカウトの終了時に失効する。この10回は確定カウントと確率上昇の対象になる。
- 印報酬：1つの特別スカウトで累計240回引くごとに、ピックアップ対象オペレーターの印（潜在強化用の重複アイテム）を1個入手できる。

## 過去のピックアップオペレーターが出なくなる理由

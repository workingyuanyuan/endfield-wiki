## レベルと昇進

オペレーターは4回の昇進を経てレベル90に到達し、レベル上限は40、60、80、90へと上がる。昇進・Ⅰから昇進・Ⅲの素材は35人のオペレーター全員で共通である。昇進・Ⅳには協約ディスクセット×36、折金券×100,000、貴重素材1種×20、菌類1種×8が必要で、オペレーターごとに異なるのはこの貴重素材と菌類の種類のみである。レア度による費用の差はない。

## レベル上限と昇進素材

| 昇進 | 昇進後のレベル上限 | 素材（全オペレーター共通） | この段階での装備解放 |
| --- | --- | --- | --- |
| なし | 20 | | |
| 昇進・Ⅰ | 40 | 協約ディスク×8、薄紅茸×3、折金券×1,600 | 装備適正・Ⅰ：青品質の装備、折金券×1,600 |
| 昇進・Ⅱ | 60 | 協約ディスク×25、紅色茸×5、折金券×6,500 | 装備適正・Ⅱ：紫品質の装備、折金券×6,500 |
| 昇進・Ⅲ | 80 | 協約ディスクセット×24、深紅茸×5、折金券×18,000 | 装備適正・Ⅲ：金品質の装備、折金券×18,000 |
| 昇進・Ⅳ | 90 | 協約ディスクセット×36、貴重素材×20、菌類×8、折金券×100,000 | |

4回の昇進の合計は協約ディスク×33、協約ディスクセット×60、折金券×126,100で、3つの装備適正ノードにさらに折金券×26,100がかかる。昇進・Ⅱ、昇進・Ⅲ、昇進・Ⅳには、それぞれ前の装備適正ノードの解放が必要である。

レベル1からの累計レベルアップ費用は全オペレーター共通である。

| 到達レベル | オペレーターEXP | 折金券 |
| --- | --- | --- |
| 20 | 22,860 | 820 |
| 40 | 271,400 | 13,360 |
| 60 | 747,110 | 37,260 |
| 80 | 1,212,340 | 146,440 |
| 90 | 1,792,290 | 385,420 |

したがって、レベル1から90までの育成と4回の昇進には合計でEXP 1,792,290と折金券×511,520が必要である。レベル60までは作戦記録で、レベル61から90までは認識媒体でEXPを得る。レベル上限を超えた分のEXPは武器EXPと異なり返還されず失われる。

## スキルレベル

各オペレーターには4つのスキル（通常攻撃、戦技、連携技、必殺技）があり、素質・配属スキル画面の戦闘スキル欄で1つずつ強化する。各スキルはランク1〜9と特化1〜3の計12段階である。各段階に必要な昇進と費用はどのスキルでも同じである：

| スキルレベル | 必要な昇進 | この段階の費用 |
| --- | --- | --- |
| 1 | なし | 初期レベル |
| 2 | 昇進・Ⅰ | 協約角柱×6、折金券×1,000 |
| 3 | 昇進・Ⅰ | 協約角柱×12、折金券×2,700 |
| 4 | 昇進・Ⅱ | 協約角柱×16、折金券×3,200 |
| 5 | 昇進・Ⅱ | 協約角柱×21、折金券×4,200 |
| 6 | 昇進・Ⅱ | 協約角柱×27、折金券×5,400 |
| 7 | 昇進・Ⅲ | 協約角柱セット×6、折金券×8,200 |
| 8 | 昇進・Ⅲ | 協約角柱セット×8、折金券×10,500 |
| 9 | 昇進・Ⅲ | 協約角柱セット×15、折金券×18,000 |
| 特化1 | 昇進・Ⅳ | 存続の痕跡×1、協約角柱セット×15、折金券×24,000 |
| 特化2 | 昇進・Ⅳ | 存続の痕跡×2、協約角柱セット×24、折金券×30,000 |
| 特化3 | 昇進・Ⅳ | 存続の痕跡×3、協約角柱セット×50、折金券×65,000 |

レベル2〜9では植物素材も1〜2個必要で、特化ではさらに貴重素材と植物素材が必要になる。1つのスキルをレベル1から特化3まで上げるには、折金券×172,200、協約角柱×82、協約角柱セット×118、存続の痕跡×6と、これらの素材がかかる。バージョン1.4でスキル特化素材の赤槍葉が追加された。

レベルアップで変わる項目：

- ダメージ倍率が上がる。例えばレーヴァテインの戦技「焼滅」の基礎爆発ダメージ倍率は、レベル1の62%からレベル12の140%まで上昇する。
- SP消費、必殺チャージ消費、必殺技のクールタイムはレベルで変わらない。変わるのは連携技のクールタイムのみで、レベル12では23人が1秒短縮、10人が2秒短縮され、[アークライト](/ja/operators/arclight/)のみ3秒のまま変わらない。

## 素質と素質・配属スキル画面

素質・配属スキル画面にはオペレーターのスキル、素質、昇進の進行状況が表示される。素質ノード欄では、能力値強化（昇進で4段階が解放され、さらに信頼度20%、50%、100%、100%が必要）、2つの素質、2つの配属スキル、3つの装備適正ノード、および昇進の各ノードを解放する。

各オペレーターは2つの素質を持ち、昇進によって解放・強化される：

| 1つ目の素質 | 2つ目の素質 | オペレーター |
| --- | --- | --- |
| 昇進・Ⅰで解放、昇進・Ⅱで強化 | 昇進・Ⅱで解放、昇進・Ⅲで強化 | 27人 |
| 昇進・Ⅰで解放、昇進・Ⅱで強化 | 昇進・Ⅲで解放 | [アケクリ](/ja/operators/akekuri/)、[ペリカ](/ja/operators/perlica/)、[ザイヒ](/ja/operators/xaihi/) |
| 初期解放、昇進・ⅠとⅢで強化 | 昇進・Ⅱで解放、昇進・Ⅲで強化 | [レーヴァテイン](/ja/operators/laevatain/)、[ティフォロス](/ja/operators/typhoeus/) |
| 初期解放、昇進・Ⅱで強化 | 昇進・Ⅰで解放、昇進・Ⅲで強化 | [オクギ](/ja/operators/arcane/) |
| 初期解放、昇進・ⅠとⅡで強化 | 昇進・Ⅱで解放 | [アルデリア](/ja/operators/ardelia/) |

## 潜在と印

各オペレーターには5段階の潜在があり、潜在は0から5まで上がる。1段階ごとにそのオペレーターの印が1つ必要で、印は同じオペレーターを重複獲得すると手に入る。各特別スカウトで累計240回スカウトするごとにも、ピックアップ中の星6オペレーターの印が1つもらえる（[スカウトの確率と天井](/ja/systems/headhunting/)を参照）。潜在1・3・5では、帝江号に飾れるオペレーターの記念画像も解放される。星6オペレーターは潜在MAXになると外観が変化し、通常は装備に光の効果が加わる。バージョン1.2でこの潜在MAXエフェクトの表示切り替えスイッチが追加された。

## 能力値

各オペレーターには4つの能力値があり、それぞれ1つのステータスを上げる。加えて、オペレーターのメイン能力は攻撃力を大きく、サブ能力は攻撃力を小さく上げる。

| 能力値 | 上昇するステータス | メイン能力とするオペレーター |
| --- | --- | --- |
| 筋力 | 基礎HP | 9人 |
| 敏捷 | 物理耐性 | 10人 |
| 知性 | アーツ耐性 | 7人 |
| 意志 | 受ける回復効率 | 8人 |

能力値はレベル、装備、潜在のほか、能力値強化ノードでも上昇する。

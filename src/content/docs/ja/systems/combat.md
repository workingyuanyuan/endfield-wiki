『アークナイツ：エンドフィールド』のダメージは物理、アーツ、超域の3種に分かれ、アーツダメージはさらに灼熱、電磁、寒冷、自然に分かれる。アーツ攻撃は敵にアーツ付着を残し、最大4スタックまで重なる。同じ属性の付着を重ねるとアーツ爆発が起き、別の属性の付着を重ねるとアーツ異常（燃焼、感電、凍結、腐食）が発生する。物理異常の攻撃は最初の一撃で敵をクラッシュ状態にし、以降は浮遊と転倒でクラッシュを重ね、猛撃と破砕でスタックを消費する。ブレイク値が満タンになると敵はブレイク状態になり、終撃を入れられる。ダメージは基礎ダメージ（通常は攻撃力基準）、会心、ダメージボーナス、対象の防御力と耐性、ブレイク状態などの乗算で決まる。バージョン1.0におけるNGAフォーラムのプレイヤー検証では、防御乗算枠は 100 / (防御力 + 100)（一般的な敵の基礎防御力100では0.5）、ブレイク状態の敵へのダメージは×1.3とされている。

## ダメージ計算式

以下の計算式は、バージョン1.0でNGAフォーラムのプレイヤー666bjが検証したものである。通常ダメージ（物理異常、アーツ異常、アーツ爆発以外のすべての命中）は、次の乗算枠の積になる。

| 乗算枠 | 値 | 複数効果の重ね方 |
| --- | --- | --- |
| 基礎ダメージ | ダメージ倍率 × 効果の参照ステータス（通常は攻撃力）＋ 基礎ダメージ固定加算 | |
| 会心 | 会心時は 1 + 会心ダメージ、非会心時は 1。期待値は 1 + 会心率 × 会心ダメージ | |
| ダメージボーナス | 1 + すべてのダメージボーナスの合計（ダメージ種類、スキル種別、ブレイク中の敵へのダメージなど） | 加算 |
| ダメージ軽減 | 各 (1 − 軽減率) の積 | 乗算 |
| 増幅効果 | 1 + 増幅効果の合計 | 加算 |
| 弱体化効果 | 各 (1 − 弱体化効果) の積 | 乗算 |
| 加護 | 1 − 最も高い加護 | 最大値のみ適用 |
| 脆弱効果 | 1 + 脆弱効果の合計 | 加算 |
| その他の被ダメージ増加 | 1 + 脆弱効果と表記されない被ダメージ増加効果の合計（感電によるアーツ被ダメージ増加、破砕による物理被ダメージ増加など） | 加算 |
| 防御力 | 有効防御力が0以上のとき 100 / (防御力 + 100)。防御無視ダメージでは 1 | |
| ブレイク | ブレイク状態の敵には 1.3、それ以外は 1 | |
| 耐性 | 1 − 耐性 / 100 + 無視した耐性 / 100 | |
| 非操作中 | 1。操作中でないオペレーターに対する一部強敵の攻撃では 0〜0.7 | |
| リンク | リンク1〜4スタックで、戦技は+30%、+45%、+60%、+75%、必殺技は+20%、+30%、+40%、+50% | 重複するが1スタックごとの伸びは逓減 |
| 特殊 | 上記の乗算枠から独立したその他の効果 | 乗算 |

- 攻撃力 = [(オペレーター基礎攻撃力 + 武器基礎攻撃力) × (1 + 攻撃力%ボーナス) + 攻撃力固定ボーナス] × (1 + 能力値ボーナス)。能力値ボーナスは、メイン能力 × 0.005 + サブ能力 × 0.002（各能力値は整数部分を使用）で算出され、一部のオペレーター素質でさらに加算される。
- オペレーターの初期会心率は5%、会心ダメージは50%。敵の会心率は0%、会心ダメージは50%。
- 全スキルダメージUPは戦技、連携技、必殺技に適用され、通常攻撃には適用されない。終撃には通常攻撃ダメージUPが適用される。
- 敵の基礎防御力はレベルを問わず100であり、防御力を変える効果がなければ防御力を参照する攻撃の防御乗算枠は0.5になる。オペレーターの基礎防御力は0で、防御力は通常、装備のメインステータスから得る。
- 耐性1ポイントごとに、その属性のダメージが1%減る。ゲーム内では敵の耐性を等級で表示し、0がD、20〜40がC、50と60がBにあたる。ほとんどの敵の耐性は0か20で、一部の敵だけが1つの属性に30、35、40、50、60のいずれかを持つ。超域耐性を持つ敵はいない。全敵の数値は[敵の耐性](/ja/systems/enemies/)にある。
- オペレーターの物理耐性は 100 − 100 / (0.001 × 敏捷 + 1)、アーツ耐性は知性を使って同様に計算し、敏捷と知性は整数部分を用いる。オペレーターの耐性乗算枠は0.1を下回らない。
- ゲーム内の多くの数値は切り捨てて表示されるため、表示値から計算すると数ポイントずれることがある。

オペレーターが発生させる物理異常、アーツ異常、アーツ爆発のダメージは、上記のうち非操作中とリンクを除いた乗算枠に加え、次の2つを乗算する。

| 乗算枠 | 値 |
| --- | --- |
| レベル | アーツ異常とアーツ爆発：1 + (発生させたオペレーターのレベル − 1) / 196（レベル90で1.454）。物理異常：1 + (レベル − 1) / 392（レベル90で1.227） |
| アーツ強度 | 1 + アーツ強度 / 100 |

| ダメージ | ダメージ倍率（攻撃力基準） |
| --- | --- |
| 燃焼、感電、凍結、腐食：初撃 | 80% × (1 + 異常段階) |
| 燃焼：1秒ごとの持続ダメージ | 12% × (1 + 異常段階) |
| 粉砕（物理ダメージだが、レベル乗算枠はアーツ異常扱い） | 120% × (1 + 異常段階) |
| いずれかのアーツ爆発 | 160% |
| 浮遊、転倒 | 120%、さらにブレイク値10 |
| 破砕 | 50% × (1 + 異常段階) |
| 猛撃 | 150% × (1 + 異常段階) |

| 異常段階 1 / 2 / 3 / 4 の効果 | 値 |
| --- | --- |
| 感電：敵のアーツ被ダメージ増加 | +12% / 16% / 20% / 24%、持続 12 / 18 / 24 / 30 秒 |
| 破砕：敵の物理被ダメージ増加 | +12% / 16% / 20% / 24%、持続 12 / 18 / 24 / 30 秒 |
| 腐食：全耐性低下 | 即時に 3.6 / 4.8 / 6 / 7.2 低下し、以降1秒ごとに 0.84 / 1.12 / 1.4 / 1.68 低下、最大 12 / 16 / 20 / 24。初期持続15秒。腐食を更新しても既に下がった耐性低下量は維持される |
| 燃焼 | 10 秒 |
| 凍結 | 6 / 7 / 8 / 9 秒 |

- アーツ強度は破砕、感電、腐食の追加効果も強化し、効果量に 1 + 2 × アーツ強度 / (アーツ強度 + 300) を乗算する。潜在による×1.33など、その追加効果を定数倍する効果はその後から乗算される。浮遊と転倒では、アーツ強度1ポイントごとにブレイク値が0.5%増える。
- スキルがアーツ付着を消費せずに直接付与したアーツ異常には、原則として初撃ダメージがない。

## アーツ付着、アーツ爆発、アーツ異常

| 用語 | 内容 |
| --- | --- |
| アーツ付着 | 敵に付与される4属性のいずれかのアーツ印。属性ごとに最大4スタック。 |
| アーツ爆発 | すでに同属性の付着を持つ敵に同じ属性の付着を追加すると発生し、その属性のダメージを与える。 |
| アーツ異常 | 1体の敵に異なる2属性の付着が重なると、付着を消費して発生するアーツデバフ。ゲーム内では別の付着＋特定属性の付着と表記する（例：燃焼＝別の付着＋灼熱付着）。 |
| 異常段階 | アーツ異常や物理異常で消費した付着スタック数（またはクラッシュスタック数）。最大4。段階が高いほど効果が強い。 |

| 属性 | アーツ爆発 | アーツ異常（その属性＋別属性の付着） | 敵への異常効果 | オペレーターに4スタック付いたとき |
| --- | --- | --- | --- | --- |
| 灼熱 | 灼熱爆発：灼熱ダメージ | 燃焼 | 灼熱の持続ダメージを受ける | 燃焼：防御力を無視する灼熱の持続ダメージを受ける |
| 電磁 | 電磁爆発：電磁ダメージ | 感電 | アーツ被ダメージが増加する | 感電：短時間スタンし、一定時間アーツ被ダメージが増加する |
| 寒冷 | 寒冷爆発：寒冷ダメージ | 凍結 | 行動不能。この状態でクラッシュまたは物理異常を与えると粉砕が発生する | 凍結：一定時間行動不能になる |
| 自然 | 自然爆発：自然ダメージ | 腐食 | すべての耐性が徐々に低下する | 腐食：一定時間ダッシュ不能になり、移動速度が低下する |

敵のスキルもオペレーターに付着を蓄積させる。右端の列は、1属性が4スタックに達したときにオペレーターが受ける効果である。

## 物理異常とクラッシュ

敵への最初の一撃となる物理異常は、その異常効果を発動せず敵をクラッシュ状態にする。クラッシュは最大4スタックまで重なる。

| 物理異常 | クラッシュ状態の敵に対する効果 |
| --- | --- |
| 浮遊 | クラッシュを1スタック追加し、物理ダメージとブレイク値を与える |
| 転倒 | クラッシュを1スタック追加し、物理ダメージとブレイク値を与える（浮遊と同じ仕様） |
| 猛撃 | クラッシュをすべて消費し、大威力の物理ダメージを与える |
| 破砕 | クラッシュをすべて消費して物理ダメージを与え、一定時間、敵の物理被ダメージを増加させる |
| 粉砕 | 独立した異常ではない。凍結中の敵にクラッシュまたは物理異常を与えると凍結を消費し、大威力の物理ダメージを与える |

猛撃と破砕にもアーツ異常と同じく異常段階があり、消費したクラッシュのスタック数がそのまま段階になる。

## ブレイク、終撃、重攻撃

| 用語 | 内容 |
| --- | --- |
| ブレイク値 | 大半のスキルと、操作中のオペレーターの重攻撃で蓄積する値。ゲージが満タンになると敵がブレイク状態になる。 |
| ブレイク状態 | 一定時間、敵が行動不能になり被ダメージが増える。短時間でブレイクした敵は、最初のブレイク状態が終わった後しばらくブレイク値が溜まりにくくなる。 |
| ブレイク点 | 一部の強敵のブレイクゲージにある目盛り。到達すると敵の行動を中断させ、よろめかせる。 |
| 終撃 | ブレイク状態の敵に対する最初の通常攻撃。大ダメージを与え、SPを一部回復する。 |
| 重攻撃 | 通常攻撃コンボの最終段。操作中のオペレーターが当てるとブレイク値を与え、SPを回復する。 |

## SP、スキル、必殺チャージ

| スキル | 消費 | クールダウン | ゲームデータ 1.6の備考 |
| --- | --- | --- | --- |
| 通常攻撃 | なし | なし | 操作中でない味方は自動で攻撃する |
| 戦技 | SP | なし | 34人中33人は100 SP、[リーノ](/ja/operators/liino/)のみ25 SP |
| 連携技 | なし | あり | 各オペレーター固有の発動条件を満たしたときのみ発動可能。スキルレベル1のクールダウンは3〜40秒 |
| 必殺技 | 必殺チャージ全消費 | 発動後に短いクールダウン | 満タンのゲージが必要。オペレーターにより必殺チャージ70〜300、クールダウンは10、15、20、30秒のいずれか |

- SP（戦技ポイント）は戦技の発動に使う。時間経過で回復するほか、操作中のオペレーターの重攻撃と終撃でも回復する。
- 必殺チャージは戦技（味方全員に同量）と連携技（発動者のみ）で溜まる。必殺技で自身を強化するオペレーターは、強化状態の持続中は必殺チャージを獲得しない。
- チームは最大4人のオペレーターで構成する。全員の戦技、連携技、必殺技は手動で発動する。

## バフ、デバフ、その他の用語

| 用語 | 効果 | 同種効果の重複 |
| --- | --- | --- |
| 増幅効果 | 一定時間、対象が与える特定属性のダメージが増加する（物理増幅、灼熱増幅効果、アーツ増幅効果など） | 加算 |
| 脆弱効果 | 一定時間、対象が受ける特定属性のダメージが増加する | 加算 |
| 加護 | 一定時間、対象が受けるダメージが減少する | 最大値のみ適用 |
| 弱体化効果 | 一定時間、対象が与えるダメージが減少する | 重複するが線形ではない |
| シールド | 持続中ダメージを吸収する。特定のダメージ種類のみ吸収するシールドもある | |
| スロー効果 | 一定時間、移動速度が低下する | 最大値のみ適用 |
| 加速 | 一定時間、移動速度が上昇する | 上限まで加算 |
| 行動停止 | 持続中、対象は行動できない | |
| 浄化 | オペレーターから特定のデバフを取り除く | |
| リンク | チームの次の戦技または必殺技のダメージが増加する（戦技の方が上昇幅が大きい）。使用時に消費される | 重複するが1スタックごとの伸びは逓減 |
| SP返還量 | 条件を満たすと直前に消費したSPの一部が戻る。SP回復とは別扱いであり、SP回復に反応する効果は発動せず、返還分を消費しても必殺チャージは増えない | |
| 状態消費 | 別の効果に使われてデバフが早期に終了すること（猛撃がクラッシュを消費する、アーツ異常が付着を消費するなど） | |
| 吸収 | 特殊な方法でデバフが早期に終了すること。状態消費とはみなされない | |
| 持続ダメージ | 時間経過で与えるダメージ。会心は発生しない | |
| 固定ダメージ | 防御力と耐性を無視し、いかなるダメージ増減の影響も受けない | |

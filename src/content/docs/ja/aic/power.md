## 工場が電力不足になる理由

工場が電力不足になるのは、設備の消費電力が地域の電力網の発電量を上回ったときである。電力網の電源は協約核心であり、発電機は源石鉱物またはバッテリーを燃焼している間だけ発電量を増やす。消費電力が発電量を上回り続けると協約核心の蓄電量が減っていき、0になると予備電源ですべての設備を30分間稼働させ続けられるが、その後その地域は停電する。図面は多くの設備とその消費電力を一度に追加するが、発電量は増やさない。

## 図面を設置した後に電力不足になる理由

| 原因 | 説明 |
| --- | --- |
| 消費電力が増えた | 各設備はそれぞれの消費電力を電力網から消費する（各設備の消費電力を参照）。図面は多数の設備からなる配置を一度に設置する。 |
| 発電量が増えていない | 協約核心は電力網の唯一の電源である。各地域の初期発電量は200で、それ以上増やすには電力網につないだ発電機に燃料を投入するしかない。 |
| 設備が送電スタンドの範囲外にある | ほとんどの設備は、電力網につながった送電スタンドの供給範囲内でしか稼働しない。集成工業エリア内の送電スタンドは自動で電力網につながる。 |
| 図面の一部が未建設である | 所持していない設備は製造待ちとして配置され、不足している設備を納品して初めて実際の設備になる。 |

対処するには、発電機を増設して燃料を投入するか、設備の電源を切る。見下ろし視点では一括操作で多数の設備を一度に停止できる。

## 図面がもたらすものともたらさないもの

| 図面がもたらすもの | 図面がもたらさないもの |
| --- | --- |
| 設備とその配置（集成工業エリア内に設置） | 電力：図面内のすべての設備は設置した地域の電力網から電力を消費する |
| 所持している設備（他地域の在庫を含む） | 所持していない設備：納品するまで製造待ちのままになる |
| 地下配管の接続状態（バージョン1.4以降）と、大型化学反応炉の複数レシピ生産停止時の自動処理設定（バージョン1.3以降） | 協約核心やサブ協約核心（図面に含めることはできない） |

図面のサイズは最大50×50マスである。天有洪炉のように地域ごとの設置上限がある設備を含む図面は、設置すると上限を超える場合、製造待ちの状態であっても設置できない。

## 予備電源

| ルール | 内容 |
| --- | --- |
| 追加時期 | バージョン1.3 |
| 利用可能になる条件 | 協約核心の蓄電量が0で、発電量が消費電力を下回っているとき |
| 効果 | その地域のすべての集成工業設備が通常どおり稼働し続ける |
| 持続時間 | 30分 |
| クールダウン | 終了後12時間 |
| 自動起動 | オンライン中に地域が停電すると初期設定で自動起動する。オフにして手動で予備電源を起動することもできる |

30分が経過しても発電量が不足したままの場合、その地域は停電状態になる。

## 発電機の燃料

発電機は電力網に接続しなければ稼働せず、源石鉱物またはバッテリーを電力に変換する。

| 燃料 | 1個あたりの燃焼時間 | 燃焼中の発電量 | 1時間あたりの消費数 |
| --- | --- | --- | --- |
| 源石鉱物 | 8秒 | 50 | 450 |
| 小容量谷地バッテリー | 40秒 | 220 | 90 |
| 中容量谷地バッテリー | 40秒 | 420 | 90 |
| 大容量谷地バッテリー | 40秒 | 1100 | 90 |
| 小容量武陵バッテリー | 40秒 | 1600 | 90 |
| 中容量武陵バッテリー | 40秒 | 3200 | 90 |
| 大容量武陵バッテリー | 40秒 | 6400 | 90 |

## バッテリーのレシピ

6種類のバッテリーはいずれも包装機（消費電力20）で作る。どのレシピも10秒でバッテリーを1個生産する。大容量武陵バッテリーはゲームデータ 1.7 で追加された。

| バッテリー | 原料 | 時間 | 産出 |
| --- | --- | --- | --- |
| 小容量谷地バッテリー | 紫晶部品 ×5、源石粉末 ×10 | 10秒 | 1 |
| 中容量谷地バッテリー | 鉄製部品 ×10、源石粉末 ×15 | 10秒 | 1 |
| 大容量谷地バッテリー | 鋼製部品 ×10、高密度源石粉末 ×15 | 10秒 | 1 |
| 小容量武陵バッテリー | 息壌 ×5、高密度源石粉末 ×15 | 10秒 | 1 |
| 中容量武陵バッテリー | 壌晶 ×5、高密度源石粉末 ×20 | 10秒 | 1 |
| 大容量武陵バッテリー | 衡息壌 ×5、高密度源石粉末 ×20 | 10秒 | 1 |

| 原料 | 設備 | レシピ |

| 高密度源石粉末 | 研磨機 | 源石粉末 ×2 とサンドリーフ粉末 ×1 から高密度源石粉末 ×1、2秒 |

## 電力輸送

協約核心は電力網の起点である。地域内のすべての電力設備は、中継タワーまたは送電スタンドを介して協約核心につながっていなければならない。

| 設備 | 地域 | 役割 | 距離 |
| --- | --- | --- | --- |
| 中継タワー | 制限なし | 他の中継タワー、送電スタンド、給電端末へ電力を送る。集成工業エリア外では設備に直接給電できないが、工業発展計画の関連技術を研究すると狭い範囲に給電できるようになる。 | 接続距離80 m；バージョン1.1以降、電線が切断されない猶予距離は100 m（以前は90 m） |
| 送電スタンド | 制限なし | 電力網につながると供給範囲内の全設備に給電する。関連技術を研究すると電力輸送も可能になり、中継タワーを置けない場所で使える。 | 研究後は30 mまで電力輸送可能；バージョン1.1以降、電線が切断されない猶予距離は50 m（以前は40 m） |
| 息壌中継タワー | 武陵のみ | 電力を輸送し、付近の設備に給電する | 80 m以内の協約核心および任意の息壌電力設備に自動接続する；集成工業エリア内では距離に関係なく協約核心に接続する |
| 息壌送電スタンド | 武陵のみ | 範囲内の設備に給電し、短距離の電力輸送も行う | 80 m以内の協約核心と息壌中継タワー、30 m以内の息壌送電スタンドと他の電力設備に自動接続する；集成工業エリア内では距離に関係なく協約核心に接続する |

バージョン1.3以降、集成工業エリア内の息壌送電スタンドと息壌中継タワーは、エリア外の息壌設備とも接続できる。サブ協約核心は自身の集成工業エリア内の送電スタンドに給電する。

## 地域建設レベル

地域建設は四号谷地と武陵それぞれの発展度であり、地域建設レベルで測る。探索や拠点への物資納品で地域建設値を得てレベルを上げると、地域間転送などの機能が解放され、鉱石の産出量と設置できる設備数が増える。拠点は集成工業の製品を取引券で買い取り、取引券は商品取引での購入や、保管ボックス、端末、集成工業エリアの強化に使う。

## 地域間転送：武陵と四号谷地の間で物資を送る

地域間転送はある地域の倉庫から別の地域の倉庫へアイテムを送る機能で、協約核心の協約管理から設定する。どちらのモードも転送元地域の地域建設レベルで解放される。

| モード | 転送元の倉庫 | 転送先の倉庫 | 解放条件 |
| --- | --- | --- | --- |
| 在庫転送 | 送った物資が減る | 同量の物資が増える | 転送元地域が所定のレベルに達する |
| 無在庫転送 | 物資が減らない | 物資が増える | 転送元地域がより高いレベルに達する |

転送を設定すると、アイテムは1時間ごとに継続して送られる。四号谷地を転送元地域とする場合：

| 四号谷地レベル | 地域間転送 |
| --- | --- |
| 8 | 解放、総転送価値800 |
| 9 | 900 |
| 10 | 1,000 |
| 11 | 1,200 |
| 12 | 1,500、無在庫転送を解放 |

武陵バッテリーで四号谷地の発電機を動かす場合：

- 地域間転送で送られた物資は四号谷地の倉庫に届く。倉庫からは協約核心やサブ協約核心の搬出口、または倉庫搬出口で指定したアイテムをベルトコンベアへ送り出し、発電機へ運ぶ。
- 小容量武陵バッテリー、中容量武陵バッテリー、大容量武陵バッテリーは発電機の燃料で、発電量はそれぞれ1600、3200、6400、燃焼時間は1個40秒である。発電機1台あたり1時間に90個消費する。
- 3種類の武陵バッテリーはいずれも包装機で作る（レシピは[集成工業の電力](/ja/aic/power/)を参照）。

## 拠点と取引券

| 項目 | ルール |
| --- | --- |
| 拠点の役割 | 連絡が取れると拠点取引が開き、拠点は時間経過で取引券を蓄積する。拠点が求める物資を取引すると取引券を得られる |
| 上限 | 取引券は上限に達すると取引するまで蓄積が止まる。拠点の取引券が尽きたら、再び溜まるのを待つ必要がある |
| 発展値 | 取引で拠点発展値を得て、一定量に達すると拠点の発展段階が上がり、より多く高品質な物資を求めて報酬も増える |
| サブ協約核心 | 各拠点には最初からサブ協約核心が1つある |
| 派遣オペレーター | オペレーターを拠点に派遣できる。陣営、趣味、特長が拠点と一致すると拠点の効率が上がる |
| エリア防御 | 警備端末で行う。各段階をクリアするごとに取引券の蓄積速度が上がる |

谷地取引券は四号谷地の商品取引で、武陵取引券は商品取引・武陵で使う。取引券は集成アシスタントでの集成工業エリアの拡張にも使い、エリアを広げられる。

武陵の拠点は3か所ある。天王原建設支援拠点（バージョン1.1と1.3でレベル上限引き上げ）、心臓修復施設（バージョン1.2で追加）、満天台建設基地（バージョン1.4で追加、武陵 - 応龍関）である。四号谷地にも拠点が3か所ある。

拠点が買い取るバッテリー：

| バッテリー | 価格 | 買い取る拠点 |
| --- | --- | --- |
| 小容量谷地バッテリー | 谷地取引券 30 | 四号谷地の3か所中1か所 |
| 中容量谷地バッテリー | 谷地取引券 30 | 四号谷地の3か所中3か所 |
| 大容量谷地バッテリー | 谷地取引券 70 | 四号谷地の3か所中3か所 |
| 小容量武陵バッテリー | 武陵取引券 25 | 武陵の3か所中2か所 |
| 中容量武陵バッテリー | 武陵取引券 54 | 武陵の3か所中3か所 |

## 商品取引と時価商品

- 商品取引では取引券でアイテムを割引価格で購入できる。商品取引担当を増やしたり強化したりすると、並ぶアイテムが増える。
- アイテムには在庫上限があり、一部は毎週更新される。端末は取引券でレベルを上げる。
- 時価商品は毎日価格が変動するため、安く買って高く売る。フレンドの船では現地と価格が異なるため、そこで手持ちを売却できる。時価商品は地域の最初の端末がレベル2に達すると解放される。

## 保管ボックスとパッキング・配達

- 保管ボックスを解放・強化すると、地域倉庫の保管上限が増える。四号谷地に3か所、武陵に2か所あり、武陵の2か所目は武陵 - 実験区域にバージョン1.2で追加された。
- パッキング・配達：保管ボックスで貨物をパッキングし、集荷地点から配送地点まで運んで取引券を得る。貨物は破損させずに届けるのが望ましく、ジップライン設備を使うと速く安全に運べる。1日に受注できる依頼には上限がある。保管ボックスを強化すると、運べる貨物の種類が増え、より大きな荷物が解放される。
- 受注した配達依頼は任務画面から他のプレイヤーへ外部委託できる。他のプレイヤーが完了すると、双方が同額の取引券精算を受け取る。

期限内に完了しなかった外部委託の扱いについては、2つの情報源で記述が食い違う。ゲーム内チュートリアルでは、双方とも取引券精算の半分を受け取れるとしている。一方、バージョン1.6の開発通信では、バージョン1.6以降、一定時間誰も受注しなかった外部委託は他の協力者が引き受けて完了するとしている。

## 地域建設レベル

| 項目 | ルール |
| --- | --- |
| 上げ方 | 探索、拠点への物資納品、新しい鉱床への採鉱機設置、拠点・資源回収所・商品取引端末・保管ボックス・環境観測端末の強化、任務の完了で地域建設値を得る |
| 上がるもの | 新機能の解放、鉱石の産出量、設備設置上限（エリアごとの協約容量、ジップライン設置上限、戦闘設備上限、鉱物純度） |
| 例 | 武陵城の協約容量は初期200、レベル3で250、レベル5で300、レベル7で上限の350になる |
| レベル上限 | 四号谷地は最大レベル12。バージョン1.1から1.7まで毎バージョンで武陵の上限が引き上げられた |
| 業務一覧 | バージョン1.3以降、地域建設画面の業務一覧から商品取引、保管ボックス、およびマップ上の位置を確認できる |

## 生産設備の仕組み

1台の生産設備が同時に実行できるレシピ（生産レシピ）は1つだけで、投入されたアイテムがいずれかのレシピに一致するとすぐ生産を始める。アイテムは他の設備や倉庫からベルトコンベアで、液体はパイプで運ばれ、製品はベルトコンベアで次の設備、倉庫搬入口、または協約貯蔵箱へ送られる。

## 設備の搬入と搬出

- 協約核心、サブ協約核心、およびほとんどの生産設備には搬入口と搬出口がある。搬出口から伸ばしたベルトコンベアはアイテムを送り出し、搬入口につないだベルトコンベアはアイテムを送り込む。
- 協約核心とサブ協約核心の搬入出口は地域の倉庫につながっている。搬出口でアイテムを指定すると、そのアイテムを倉庫から送り出す。他の設備の搬入出口はその設備自身の保管枠にだけつながっている。
- 道具箱や倉庫から手動でアイテムを設備へドラッグして投入し、製品を取り出すこともできる。
- 設備の画面では左側に搬入口と送られてくる原料、右側に搬出口と送り出される製品が表示される。
- 設備が詰まると搬入と搬出が止まり、画面に警告が表示される。
- 武陵の一部の設備にはパイプをつなぐ液体ポート付きの液体モードがあり、モードを切り替えると実行できるレシピが変わる。バージョン1.4以降、設備を設置する前にモードを選べる。

## 物流装置

| 装置 | 役割 | 制限 |
| --- | --- | --- |
| ベルトコンベア | 設備間でアイテムを運ぶ | 集成工業エリア内のみ；設備または設置済みのベルトコンベアからつなぐ必要がある |
| ベルトブリッジ | 2本のベルトコンベアを混ぜずに交差させる | |
| 分流器 | 1本のベルトコンベアを最大3本に均等に分ける | |
| 合流器 | 最大3本のベルトコンベアを1本に合流させる | |
| パイプ | 液体ポート間で液体を運ぶ | 1区間ごとの長さ上限あり；端のパイプ支柱から次の区間をつなぐ |
| 地下配管（入）と地下配管（出） | 対になる2点間で液体を地下輸送する | バージョン1.4以降は直線距離で300 m（以前は200 m） |
| 倉庫連結ハブ基礎と倉庫連結ハブ部品 | 倉庫連結ハブを構成する：基礎が起点、部品で延長する | 基礎は集成工業エリア内の任意の場所に設置可；部品は基礎または稼働中の部品につなぐ |
| 倉庫搬出口 | 指定した倉庫アイテムをベルトコンベアへ送り出す | 倉庫連結ハブに隣接して設置する |
| 倉庫搬入口 | ベルトコンベアで届いたアイテムを倉庫にしまう | 倉庫連結ハブに隣接して設置する |
| 協約貯蔵箱 | アイテムを保管し、給電中は倉庫へ転送する。ラインの終端に置くことが多い | 消費電力5 |
| 液体貯蔵タンクとガス貯蔵タンク | 液体と気体を貯蔵する | |

## 協約容量

地域ごとに独立した協約容量がある。集成工業エリアの外に設備を設置すると協約容量を消費し、消費量は設備の種類ごとに異なる。地域の協約容量を使い切ると、その地域にはそれ以上設備を設置できない。地域建設レベルが上がると上限が増える（[地域建設](/ja/aic/regional-development/)を参照）。

## 大型化学反応炉：複数レシピ生産停止時の自動処理

バージョン1.3以降、大型化学反応炉が複数のレシピを実行していてそのすべてが詰まったとき、キャッシュを空にして反応を続けられるようにする。この設定は初期状態でオンになっており、図面にも保存される。

## 仕組み

フィールドに設備を置いて鉱石を採掘し、精錬して加工し、地域の電力網から電力を送る。製品は装備、戦術アイテム、設備、交易品の素材になる。四号谷地と武陵にはそれぞれ集成工業があり、その中心に協約核心が1つある。電力網、倉庫、設置上限は地域ごとに別々である。

## 中心となる設備

| 設備 | 役割 |
| --- | --- |
| 協約核心 | 地域の集成工業の中心。地域の電力網の唯一の電源で、協約転送ポイントでもあり、協約管理（地域間転送）を開く場所でもある。搬入口と搬出口は地域の倉庫につながっている。 |
| 集成工業エリア | 協約核心またはサブ協約核心の周りのエリア。ここに置いた送電スタンドは自動で電力網につながり、ベルトコンベアはここにしか置けない。協約転送ポイントの近くと同じく、ここでは道具箱が倉庫につながる。 |
| サブ協約核心 | 自分の集成工業エリアで同じ役割を持つ副次的な核心：協約転送ポイント、倉庫の搬入出口、エリア内の送電スタンドへの自動給電。拠点ごとに1つあり、協約核心と電力でつながっているときだけ動く。 |
| 集成アシスタント | 集成工業エリアのそばに立っている。ここで地域の取引券を使うとエリアが広がる。 |
| 工業発展計画 | 集成工業の技術の研究ツリーで、3段階ある。メイン任務で手に入る拡張核心で次の段階が開く。 |

協約核心とサブ協約核心は手動では置けず、移動だけができる。そのため図面に含まれることはない。

## 集成工業がある地域

| 地域 | その地域の名を持つバッテリー | 拠点 |
| --- | --- | --- |
| 四号谷地 | 小容量・中容量・大容量谷地バッテリー | 3 |
| 武陵 | 小容量・中容量武陵バッテリー | 3：天王原建設支援拠点、心臓修復施設（バージョン1.2）、満天台建設基地（バージョン1.4） |

倉庫は地域ごとにあり、ある地域を探索している間はその地域の倉庫にしか触れられない。帝江号では、管理する地域倉庫を切り替えられる。バージョン1.4以降、武陵に入って協約核心を置くと一部の設備が早めに解放されるが、四号谷地では基礎工業計画の該当技術を研究するまで使えない。

## バージョンごとの集成工業の変更

| バージョン | 集成工業の変更 |
| --- | --- |
| 1.1 | 武陵工業Ⅱ：水力採鉱機、地下配管（入）と地下配管（出）、赤銅鉱物。集成工業エリアに戻らなくても、素材からどこでも設備を建てられるようになった。電線がより遠くまでつながったままになった（[集成工業の電力](/ja/aic/power/)を参照）。 |
| 1.2 | 武陵工業Ⅲ：耐酸性液体ポンプⅡ、多口地下配管（入）と多口地下配管（出）、精製機、大型化学反応炉。新しい拠点、心臓修復施設。 |
| 1.3 | 予備電源。地域建設画面の業務一覧。大型化学反応炉の複数レシピ生産停止時の自動処理。集成工業エリア内の息壌送電スタンドと息壌中継タワーが、エリア外の息壌設備につながるようになった。 |
| 1.4 | 武陵のガス工業モードとガス設備。新しい拠点、満天台建設基地。フィールドの設備をマップから倉庫にしまえるようになった。地下配管の範囲が最大300 mになった。 |
| 1.5 | 設備の連続設置。範囲選択中に図面の設備上限が表示されるようになった。 |
| 1.6 | スーの絵と、その後の武陵城の農地のための自動農業マシン。道具箱やどの倉庫からでも設備を直接置けるようになり、どの倉庫の素材からでも建てられるようになった。 |
| 1.7 | 武陵に[陣関連の集成工業モード](/ja/aic/arrays/)が加わり、均衡炉、晦明炉、双影晦明炉、再建用供給口が追加された。封鎖区域再建。廃水処理機は無害化処理機に改称された。通過制御口とパイプ通過制御口を設備の出入口に直接設置できるようになった。 |

バージョン1.1から1.7までのどのバージョンでも、武陵の地域建設レベルの上限が上がった。

## 図面共有のルール

図面共有コードを共有すると、誰でもその設計を見て、コピーして使える。差別、誹謗中傷、わいせつ、暴力、賭博、憎悪など、ゲーム利用規約で禁じられた内容を示す設置物や図面は、設置物の削除、集成工業機能の制限、アカウント停止の対象になることがある。

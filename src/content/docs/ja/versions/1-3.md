バージョン1.3「拾遺散記」は正式リリース後3回目のアップデートであり、新規ストーリーはサブ任務と探索任務で構成される。アップデートメンテナンスは2026-06-05の06:00から12:00まで行われた。

## 新規コンテンツ

| 種別 | 追加内容 |
| --- | --- |
| サブ任務 | 「谷に秘められし剣」「心映す一拳」「死の舞踏」 |
| 探索任務 | 「拠点建設・天王原建設支援拠点・3」「崖にて剣を論ず」「選剣演武」 |
| エリア | 武陵 - 蔵剣谷 |
| オペレーター | [ミ・フ](/ja/operators/mi-fu/)と[カミーユ](/ja/operators/camille/)（いずれも星6） |
| 星6武器 | 赤纓（大剣）、ファントムペイン（大剣）、カーマインヴェール（長柄武器）、灯火の使命（長柄武器） |
| 敵 | 山吼獣、鎧裂獣、大山吼獣 |
| 装備 | 装備セット「清波」「宏山点剣」「旧鋒」に一部装備を追加 |

## スカウトと武庫申請（ガチャ・武器ガチャ）

| 名称 | 種類 | ピックアップ | 開始 | 終了 |
| --- | --- | --- | --- | --- |
| 「拳に悔い無し」 | 特別スカウト | ミ・フ | アップデート後 | 2026-06-26 11:59 |
| 「赫結・申請」 | 武庫申請 | 赤纓（大剣） | アップデート後 | 「拳に悔い無し」から数えて特別スカウト3回終了後 |
| 「咎の番人」 | 特別スカウト | カミーユ | 2026-06-26 12:00 | バージョン1.4アップデート時（2026-07-16） |
| 「染紅・申請」 | 武庫申請 | カーマインヴェール（長柄武器） | 2026-06-26 12:00 | 「咎の番人」から数えて特別スカウト3回終了後 |

ミ・フとカミーユは、それぞれの開催回に続く2回の特別スカウトでも、ピックアップ対象外として特別スカウトのラインナップに残る。

各スカウトで出現する星6オペレーター：

| スカウト | 出現する星6オペレーター |
| --- | --- |
| 「拳に悔い無し」 | ミ・フ、[ゾアン・ファンイ](/ja/operators/zhuang-fangyi/)、[ロッシ](/ja/operators/rossi/)、[エンバー](/ja/operators/ember/)、[リーフォン](/ja/operators/lifeng/)、[アルデリア](/ja/operators/ardelia/)、[ラストライト](/ja/operators/last-rite/)、[ポグラニチニク](/ja/operators/pogranichnik/) |
| 「咎の番人」 | カミーユ、ミ・フ、ゾアン・ファンイ、エンバー、リーフォン、アルデリア、ラストライト、ポグラニチニク |

ロッシは「拳に悔い無し」のラインナップに含まれるが、「咎の番人」には含まれない。ピックアップされたオペレーターは3回の特別スカウトの間ラインナップに残り、その後外れて通常スカウトにも追加されない。「拳に悔い無し」は、バージョン1.1の「ウルフパール」から数えてロッシの3回目の特別スカウトである。[バージョン1.2](/ja/versions/1-2/)の特殊スカウト「輝きの祝典」は数えない。[スカウトの確率と天井](/ja/systems/headhunting/)および[武庫申請と基質](/ja/systems/arsenal/)も参照。

## システム変更

- 集成工業：いずれかの地域が停電した際、予備電源がその地域のすべての設備へ一定時間電力を供給し、その後再使用までに回復時間が必要となる。
- 集成工業：地域建設画面に業務一覧が追加され、商品取引や保管ボックスの情報とマップ位置をまとめて確認できる。メインメニューにレポート画面へのショートカットが追加された。
- 集成工業：大型化学反応炉は、すべてのレシピが生産停止になった際に臨時保管スペースを自動で空にする（複数レシピ生産停止時の自動処理、デフォルトで有効、図面に保存される）。
- 集成工業：武陵の集成工業エリア内にある息壌送電スタンドと息壌中継タワーが、外部の息壌電力設備と接続できるようになった。武陵の地域建設レベル上限と天王原建設支援拠点の拠点レベル上限が引き上げられた。
- 装備の精密加工に一括補充が追加され、未加工の装備を素材として複数選び、成功するまで連続で加工でき、使われなかった素材は返還される。
- 武器：貴重品倉庫で星6以外の武器を一括処分できるようになった。星5武器はすべてを一括でロック・解除でき、潜在上限に必要な本数を超えた分だけを一括解除することもできる。
- 基質厳選リスト（探索レベル4で解放）：リストに登録した武器の全効果と一致する純粋基質は自動でロックされ、完全適応と表示される。
- デイリークエスト：理性を60または120消費するクエストの活躍度が10から20へ引き上げられた。「敵を計20体倒す」は「敵を計10体倒す」に変更された。活躍度20のクエストが2種類追加された。
- 戦闘：ターゲットのロックオン切り替え時の表示がわかりやすくなり、画面外の敵からの攻撃に警告が追加された。
- その他：フレンド訪問後に自分の帝江号へ戻る機能、重要なイベントの開始・更新・終了直前にイベント画面で通知を表示する機能、モバイル版でオン・オフできるシステム通知が追加された。
- 不具合修正：動的侵蝕内で戦闘不能になったオペレーターが動的侵蝕内で復帰する不具合、一部オペレーターの効果音の異常、一部モバイル端末のメイン任務第二章プロセスⅢ「泉涸れて潮生ず」でペリカのモデルが異常になる不具合を修正。

| --- | --- |
| 灼熱焔痕 | レーヴァテイン、ギルベルタ、イヴォンヌ、エンバー、リーフォン、アルデリア、ラストライト、ポグラニチニク |
| ふわふわトランスポーター | ギルベルタ、イヴォンヌ、レーヴァテイン、エンバー、リーフォン、アルデリア、ラストライト、ポグラニチニク |
| 超イケイケカラフル | イヴォンヌ、ギルベルタ、レーヴァテイン、エンバー、リーフォン、アルデリア、ラストライト、ポグラニチニク |

ギルベルタとイヴォンヌは自身のスカウト開始前、正式リリース時から排出対象に入っていた。3つのスカウトの排出対象はいずれも同じ8名である。

## バージョン期間中の変更

- 2026-02-04より前のアップデートで、集成工業の模擬空間の報酬受取方法が変更され、一部の敵のステータスや耐性が引き下げられた。
- 2026-02-05 08:00から08:10のアップデートで以下の変更が行われた：探索レベル6の敵レベルを60から55へ、探索レベル7を70から60へ引き下げ（ドロップは変更前と同一）；行動レベル16から18で青鉄装備部品、28から30で高晶装備部品を入手可能（各レベルで装備4個分）；見下ろし視点で選択中の設備を一括でオン・オフ可能に；一部の協約転送ポイント、希少採集物、鉱物スポット周辺の敵配置を変更；一部の打撃装置の難易度を緩和。
- このアップデート以降、メイン任務第一章プロセスⅠ「基地救援」を完了したすべてのアカウントに、通常スカウトの星6オペレーターを1名指名できる指名招集券×1がゲーム内メールで配布される。

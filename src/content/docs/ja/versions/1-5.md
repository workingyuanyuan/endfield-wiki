バージョン1.5「雪氷の幽夢」は正式リリース後5回目のアップデートである。アップデートメンテナンスは2026-09-02の06:00から12:00まで行われた。武陵の2エリアが開放され、独自の天井ルールを持つ再現スカウトと再現申請が初めて登場した。

| 種別 | 追加内容 |
| --- | --- |
| サブ任務 | 「冬の夢は霧の中に」「命の果てに」「運命の啓示」 |
| エリア | 武陵 - 雪松林、武陵 - 遂明 |
| オペレーター | [ティフォロス](/ja/operators/typhoeus/)（星6）、[プチエナ](/ja/operators/purrchena/)（星5） |
| 星6武器 | 寒夜の影（アーツユニット）、苦難の果（アーツユニット） |
| 星5武器 | スイーツタイム（片手剣） |
| 敵 | ムシ型ゴーレム、巡回ゴーレム、樹海の怒 |
| 装備セット | 天険 |
| 訓練ステージ | ティフォロスの射場（初回クリア報酬あり） |

プチエナはイベント「でっかいフェリーン！襲来！」で無料入手でき、どのスカウトにも含まれない。

| --- | --- | --- | --- | --- |

| 「超爆盛れカラフル」 | 再現スカウト#1 | [イヴォンヌ](/ja/operators/yvonne/) | 2026-09-24 12:00 | バージョン1.6アップデート時（2026-10-15） |

各スカウトで出現する星6オペレーター：

| スカウト | 出現する星6オペレーター |
| --- | --- |
| 「冬狩」 | ティフォロス、[リーノ](/ja/operators/liino/)、[オクギ](/ja/operators/arcane/)、[エンバー](/ja/operators/ember/)、[リーフォン](/ja/operators/lifeng/)、[アルデリア](/ja/operators/ardelia/)、[ラストライト](/ja/operators/last-rite/)、[ポグラニチニク](/ja/operators/pogranichnik/) |
| 「超爆盛れカラフル」 | イヴォンヌ、エンバー、リーフォン、アルデリア、ラストライト、ポグラニチニク |

「冬狩」はこのバージョンで唯一の特別スカウトである。[カミーユ](/ja/operators/camille/)は[バージョン1.4](/ja/versions/1-4/)の最後の特別スカウトには含まれていたが、「冬狩」には含まれない。ピックアップされたオペレーターは3回の特別スカウトの後にラインナップから外れ、通常スカウトにも追加されない。[スカウトの確率と天井](/ja/systems/headhunting/)も参照。

再現スカウトと再現申請のルール：

- 「超爆盛れカラフル」：最初の120回以内でイヴォンヌが確定する。緊急招集により累計30・60・90回でそれぞれ無料の10連スカウト1回分を得られ、累計240回ごとにイヴォンヌの印×1を受け取れる。これらのカウントはすべて以降の「超爆盛れカラフル」へ引き継がれ、確定天井と緊急招集の特典はそれら全体を通して1回のみ適用される。
- 「点描・申請」：連続3回の申請で星6武器が出なかった場合、4回目で必ず星6武器が出る。このカウントは再現申請#1内のみで有効である。最初の7回の申請で芸術の独裁者が出なかった場合、8回目で必ず出る。このカウントは以降の「点描・申請」へ引き継がれ、1回のみ適用される。
- 特別スカウト券は、特別スカウトだけでなく再現スカウトでも使える。

## システム変更

- 育成強化一覧（オペレーター画面内）：所持済み・未所持・近日実装予定のオペレーターと武器について、各育成目標に必要な素材と所持数をまとめて確認できる。
- 集成工業：武陵の地域建設レベル上限と拠点「満天台建設基地」のレベル上限が引き上げられた。連続設置をオンにすると、設備・装飾品・畑を連続して設置する間も設置状態が維持される。
- ストーリー会話中にUIを非表示にでき、自動再生と併用できる。一部ステージの集計画面にクリア時間が表示される。
- 応接室：「一括配置」で配置可能な手がかりをすべて自動でセットでき、「重複分を一括譲渡」で余った手がかりをフレンドへまとめて贈れる。
- 信頼度が最大のオペレーターへプレゼントを贈っても、プレゼント関連クエストに計上される。
- 不具合修正：オクギが「陣訣・知」形態で特定の操作を行うと、戦技のSP返還とダメージが異常になる不具合を修正。
- 不具合修正：リーノの戦技が敵に初めて命中した際、チャージ状態の中断回数が異常になる不具合を修正。
- 不具合修正：「向淵行」アップデート以降、必殺技チャージを回復する戦闘補助アイテムが一部のステージ進入時に異常消費される不具合を修正。
- [ロッシ](/ja/operators/rossi/)の戦技（会心率UP）と[フローライト](/ja/operators/fluorite/)の戦技（スロー効果）の説明文を調整した。実際の効果に変更はない。
- オクギとリーノの一部モーションのボイス、および[エステーラ](/ja/operators/estella/)のアーカイブ内の一部ボイスを改善した。

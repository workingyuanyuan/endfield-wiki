バージョン1.4「向淵行」は正式リリース後4回目のアップデートであり、コアバージョンにあたる。アップデートメンテナンスは2026-07-16の06:00から12:00まで行われた。このバージョンから、第一章を終わらせなくても第一章-プロセスⅡ「修繕の進捗」の直後に武陵の第二章メイン任務を始められる。

## 新規コンテンツ

| 種別 | 追加内容 |
| --- | --- |
| メイン任務 | 第二章-プロセスⅦ「薄明、なお消えず」まで解放 |
| エリア | 武陵 - 応龍関、武陵 - 北部封鎖区域 |
| オペレーター | [オクギ](/ja/operators/arcane/)と[リーノ](/ja/operators/liino/)（いずれも星6） |
| 星6武器 | 四二式・粛陣（アーツユニット）、プリズムナイトデビュー（長柄武器）、ファーサイト（片手剣）、連結点（アーツユニット）、黄金時代（長柄武器） |
| 敵 | 「千人隊長アレイクレウス」（1体）と、応龍隊長の蝕影を含む蝕影系8種 |
| 集成工業 | 武陵のガス生産（ガス収集やガス反応装置などの工業発展計画）、ガスの不活性ガスと息壌ガス、拠点「満天台建設基地」 |
| 装備セット | 集成訓練、渡淵 |
| 素材 | タロス茸（昇進）、赤槍葉（スキル特化）、協約紋石（武器突破） |

## システム変更

- 武陵の先行解放：武陵の大半の敵は探索レベルに応じたレベルになり、武陵に協約核心を設置すると一部の集成工業設備が先行解放される。これらの設備は、対応する研究を完了するまで四号谷地では使えない。
- 戦闘：味方スキルエフェクトの品質と不透明度を設定でき、ターゲット設定が3項目（スキル目標の優先度、手動ロックオン目標、自動ロックオン方式）に分かれた。
- 新機能：タロサイト交換（応龍関と北部封鎖区域で集めたタロサイトを交換）、素材変換（道具製作で高ランク素材を低ランク素材へ変換）、誕生日、ID情報更新カード（半年に1枚無料）、所持オペレーターの2D立ち絵閲覧。
- オペレーター体験イベントの報酬に武庫装備ボックスが追加された。体験オペレーターに適した精密加工MAXのLv.60装備セットが入っている。
- 集成工業：武陵の地域建設レベル上限が引き上げられた。地下配管の接続距離は直線距離で判定され、上限が200 mから300 mに延長された。協約核心エリア外の設備をマップから遠隔収納できる。金品質装備は製造工程を切り替えられ、最新工程では取引券の消費が99%割引される。
- 装飾品が道具箱と倉庫の容量を圧迫しなくなった。スカウト詳細と申請詳細で、特別スカウトと武庫申請の90日以内の報酬履歴を確認できる。
- O.M.V.帝江号：応接室の情報共有の持続時間が24時間から20時間に短縮され、指揮中枢から船室を遠隔でアップグレードできる。
- グラフィック：PC版でNVIDIA DLSS 4.5超解像技術とAMD FSR 3に対応し、PlayStation 5 Pro版で進化版PSSRに対応した。
- 不具合修正：[アレッシュ](/ja/operators/alesh/)が潜在「人生大逆転！」を解放した後、戦技で一部の武器スキル効果が発動しない不具合を修正。
- 不具合修正：[スノーシャイン](/ja/operators/snowshine/)を操作中オペレーターとした際の特定操作で画面が異常回転する不具合、編成内の[キャッチャー](/ja/operators/catcher/)が重攻撃を行うと画面が揺れる不具合、モバイル版で[ゾアン・ファンイ](/ja/operators/zhuang-fangyi/)の落下攻撃にバイブレーションがない不具合、画面遷移時にカミーユの翼が異常表示される不具合を修正。
- ミ・フの連携技の効果音を改善した。

## 运作方式

设备摆放在野外，自动开采矿物、精炼与封装，并由地区电网供电；产物是制造装备、战术物品、工业设备与交易货品的材料。四号谷地与武陵各有一套集成工业系统，中心是一座协议核心，两个地区的电网、仓库与摆放上限互相独立。

## 核心设备

| 设备 | 作用 |
| --- | --- |
| 协议核心 | 地区集成工业的中枢，也是地区电网唯一的电力来源、协议传送点，以及开启协议管理（跨地区传输）之处。它的输入口与取货口和地区仓库相连。 |
| 集成核心区域 | 协议核心或次级核心周围的区域。摆在这里的供电桩会自动接入电网，传送带只能建在这里；在这里和协议传送点附近，背包与仓库相通。 |
| 次级核心 | 功能与协议核心类似的次要核心，在自己的集成核心区域内作为协议传送点、提供仓库的取货口，并自动为区域内的供电桩供电。每个据点有一座次级核心，次级核心必须与主协议核心有电力连接才能运作。 |
| 集成管家 | 位于集成核心区域旁；在此消耗地区调度券升级，区域面积会扩大。 |
| 工业发展规划 | 工业技术的研究树，共分三期；推进主线任务取得拓展核心后，才能开启下一期。 |

协议核心与次级核心不能自行摆放，只能移动，所以蓝图不会包含它们。

## 有集成工业系统的地区

| 地区 | 以地区命名的电池 | 据点 |
| --- | --- | --- |
| 四号谷地 | 低容量、中容量、高容谷地电池 | 3 |
| 武陵 | 低容量、中容武陵电池 | 3：天王坪援助点、心脏修缮站（1.2 版）、盈天台建设站（1.4 版） |

每个地区有自己的仓库，在某地区探索时只能存取该地区的仓库；在帝江号上可以手动切换要管理的地区仓库。自 1.4 版起，进入武陵并摆放协议核心后，会先行解锁并提供一批集成工业设备；这些设备要完成基础工业计划中对应工业技术的研究后，才能在四号谷地使用。

## 各分组的设备

设备共分十个分组：资源开采、仓保存取、基础生产、合成制造、电力供应、功能设备六组共 45 种设备，以及物流设备、战斗辅助、装饰物品与种植调配。

## 各版本的集成工业变更

| 版本 | 集成工业变更 |
| --- | --- |
| 1.1 | 开放武陵工业二期：水驱矿机、暗管入口与暗管出口、赤铜矿。设备可在地图任意位置以材料制造，无需返回集成核心区域。电线保持不断开的距离延长（见[集成工业电力](/zh-cn/aic/power/)）。 |
| 1.2 | 开放武陵工业三期：二型耐酸水泵、多口暗管入口与多口暗管出口、提纯机、扩容反应池。新增据点心脏修缮站。 |
| 1.3 | 新增备用电源；地区建设界面新增事务总览；扩容反应池新增自动处理多个配方阻塞；集成核心区域内的息壤供电桩与息壤中继器可与外部息壤电力设备连接。 |
| 1.4 | 武陵新增气体相关工业模式与气体设备；新增据点盈天台建设站；野外设备可从地图远端收回至仓库；暗管连接距离上限提升至 300m。 |
| 1.5 | 新增连续摆放；框选新建蓝图时即时显示蓝图可保存的设备数量上限。 |
| 1.6 | 新增自动农植机，用于祀的画的种植区，之后也可用于武陵城的种植区。背包或任意仓库中已有设备，或仓库内材料足以制造时，可直接摆放设备。 |
| 1.7 | 武陵新增[阵列相关的工业模式](/zh-cn/aic/arrays/)，包括平衡炉、明晦炉、分影明晦炉与重建供应端口；重建禁区。废水处理机改名为废料处理机。物品准入口与管道准入口可直接摆在设备的接口上。 |

1.1 至 1.7 版每一版也都提升了武陵的地区建设等级上限。

## 蓝图分享规范

分享蓝图分享码，就是允许任何人查看、复制与使用该设计。在集成工业系统中发布涉及歧视、诽谤、淫秽、暴力、赌博、仇恨或其他服务条款禁止的内容，可能导致摆放物被移除、集成工业功能受限或账号停权。

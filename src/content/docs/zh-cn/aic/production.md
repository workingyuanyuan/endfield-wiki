## 生产设备如何运作

每台设备同时只能生产一种配方，只要放入的物品符合任一配方，就会立刻开始生产。物品由传送带从其他设备或仓库送入，液体走管道；产物再经传送带送往下一台设备、仓库存货口或协议保存箱。

## 设备如何输入与输出

- 协议核心、次级核心与大部分生产设备都有输入口与取货口。从取货口连出的传送带把物品送出；连入输入口的传送带把物品送入。
- 协议核心与次级核心的连接口和地区仓库相连：在取货口选定物品后，它就会从仓库送出该物品。其他设备的连接口只连到设备自己的保存。
- 也可以把背包或仓库中的物品手动拖入设备，再把产物收回。
- 设备界面左侧是输入口与传送带送入的材料，右侧是取货口与送出的产物。
- 设备阻塞时，会停止输入与输出，界面下方出现阻塞警示。
- 武陵有些设备具有液体模式，多出可接管道的液体连接口；切换模式会改变设备可用的配方。自 1.4 版起，可在摆放前先选好模式。

## 物流设备

| 设备 | 作用 | 限制 |
| --- | --- | --- |
| 传送带 | 在设备之间运输物品 | 只限集成核心区域；起点必须是设备或已摆放的传送带 |
| 物流桥 | 让两条相交的传送带各自运输、互不影响 | |
| 分流器 | 把一条传送带平均分成最多三条 | |
| 汇流器 | 把最多三条传送带合并为一条 | |
| 管道 | 在液体连接口之间输送液体 | 单次摆放有长度上限；末端自动生成的管道支架可接续下一段 |
| 暗管入口与暗管出口 | 成对连接，经地下输送液体 | 1.4 版起按直线距离计算，上限 300m（原为 200m） |
| 仓库存取线源桩与仓库存取线基段 | 组成仓库存取线：源桩是起点，基段向外延伸 | 源桩可摆在集成核心区域任意位置；基段须连接源桩或已启用的基段 |
| 仓库取货口 | 把选定的仓库物品送上传送带 | 须贴靠仓库存取线摆放 |
| 仓库存货口 | 把传送带送来的物品存入仓库 | 须贴靠仓库存取线摆放 |
| 协议保存箱 | 存放物品，接入电网且电力充足时把物品传送至仓库，常放在产线末端 | 用电 5 |
| 储液罐与储气罐 | 保存液体与气体 | |

## 协议容量

每个地区都有独立的协议容量上限。在集成核心区域外摆放设备会消耗协议容量，不同设备消耗的量不同；某地区的协议容量用完后，该地区就无法再摆放新设备。地区建设等级提升会提高这些上限：见[地区建设](/zh-cn/aic/regional-development/)。

## 扩容反应池：自动处理多个配方阻塞

自 1.3 版起，扩容反应池在进行多个配方反应时，若这些配方都处于阻塞状态，会自动清空暂存区内的全部物品，让反应继续进行。此选项默认开启，且选项状态会随蓝图保存。

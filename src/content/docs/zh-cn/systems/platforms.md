《明日方舟：终末地》于 2026-01-22 11:00 公测，平台为 PC（GRYPHLINK 启动器与 Epic Games Store）、PlayStation 5、iOS 与 Android。GeForce NOW 于 2026-04-03 加入，Steam 则随 2026-10-15 的 1.6 版更新上线。只要在同一个服务器游玩，所有平台的进度都互通。

## 平台与商店

| 平台 | 客户端或商店 | 开放时间 | 登录方式 |
| --- | --- | --- | --- |
| PC（Windows） | GRYPHLINK 启动器，从官网下载 | 公测，2026-01-22 | Gryphline 账号 |
| PC（Windows） | Epic Games Store | 公测，2026-01-22 | Gryphline 账号 |
| PlayStation 5 | PlayStation Store | 公测，2026-01-22 | 仅限 PSN 账号 |
| iOS 与 iPadOS | App Store | 公测，2026-01-22 | Gryphline 账号 |
| Android | Android 客户端 | 公测，2026-01-22 | Gryphline 账号 |
| PC（Windows） | Steam，app 4732690 | 1.6 版更新后，2026-10-15 | 与 Gryphline 账号绑定的 Steam 账号 |
| 云端 | NVIDIA GeForce NOW：Windows PC、Mac、Chromebook 上的客户端，或 Chrome、Edge 中的网页版 | 2026-04-03 | Gryphline 账号 |

- Gryphline 账号可通过 Google、Apple、Facebook 等第三方账号登录。
- 每个平台都能进入两个服务器。GeForce NOW 需要 GeForce NOW 会员资格，是否可用取决于所在国家或地区。
- Steam 版与其他平台共用游戏服务器，只能通过 Steam 客户端下载与更新，无法通过 GRYPHLINK。游戏内购买经由 Steam 内嵌界面（Steam Overlay）完成。

## PC 配备需求

| 项目 | 最低配备 | 建议配备 |
| --- | --- | --- |
| 作业系统 | Windows 10 64-bit 或 Windows 11 64-bit，DirectX 11.1 及以上 | 相同 |
| 处理器 | Intel Core i5-9400F 或同等级 | Intel Core i7-10700K 同等级及以上 |
| 显示卡 | NVIDIA GeForce GTX 1060 或同等级 | NVIDIA GeForce RTX 2060 同等级及以上，驱动程式升级到最新版本 |
| 记忆体 | 16 GB | 16 GB 及以上 |
| 保存空间 | 预留 50 GB，解压缩时另需 40 GB；建议安装在固态硬碟 | 相同 |

## PC、PlayStation 5 与手机的进度互通吗？

在同一个服务器内互通。Asia 服务器与 Americas / Europe 服务器之间的账号资料一律不互通（[服务器与时间](/zh-cn/systems/servers-and-time/)）。在某个平台购买的道具，以同一个 Gryphline 账号登录其他平台也能使用。

| 平台 | 如何共用进度 |
| --- | --- |
| PC、Android、iOS、GeForce NOW | 以同一个 Gryphline 账号登录，并选择角色所在的服务器 |
| Steam | 首次启动时选择「登录已有信箱账号并绑定」，输入原有 Gryphline 账号的信箱。选择「注册并绑定」则会建立新账号 |
| PlayStation 5 | 将 PSN 账号与 Gryphline 账号绑定；服务器依 PSN 帐户所在地区决定 |

## 可以用控制器吗？

可以。PC 与行动装置支援以下控制器；使用第三方品牌控制器可能有相容性问题。

| 控制器 | PC 蓝牙连接 | 行动装置蓝牙连接 |
| --- | --- | --- |
| DualSense、DualSense Edge（PS5）、DUALSHOCK 4（PS4） | 仅支援自适应扳机；不支援震动与控制器扬声器 | 与 PC 相同 |
| Xbox 无线控制器、Xbox Elite 无线控制器 | 完整功能 | 不支援震动与自适应扳机 |

- 行动装置上的 Xbox 控制器，繁体中文的控制器常见问题写不支援自适应扳机，英文的常见问题写的是 impulse trigger（脉冲扳机）。
- 两类控制器都可用 USB 有线或蓝牙连接。在 PlayStation 5 以外的平台，以有线连接才有 PlayStation 控制器的完整功能。
- 在登录界面进行任意控制器操作，即切换至控制器界面。游戏中按下控制器按键会跳出切换提示；按下键盘按键或点击触控萤幕，则跳出切换回原操作模式的提示。
- 管理员角色选择与命名页面、教学引导、角色对话与剧情演出，以及部分战斗场景与模拟空间中无法切换操作模式。
- 文字输入：PC 使用键盘，行动装置与 PlayStation 使用系统的虚拟键盘。
- 震动与自适应扳机在「设定」→「操控」中开关，控制器扬声器在「设定」→「音讯」中设定。
- 1.2 版在「设定 - 控制器」中新增自定义按钮设定。

## PSN 账号与 Gryphline 账号绑定

| 情况 | 可行的做法 |
| --- | --- |
| 从未登录过游戏的 PSN 账号 | 首次登录并同意使用者协议后，绑定视窗可绑定已有 Gryphline 账号的信箱。跳过视窗会建立新的 Gryphline 账号，视窗也不会再出现 |
| 已有游戏进度的 PSN 账号 | 「设定」→「平台与帐户」→「帐户中心」→「绑定信箱」，绑定未注册为 Gryphline 账号的信箱 |
| 解除绑定 | 在 Gryphline 账号的帐户中心，每个账号限一次 |
| 限制 | 一个 PSN 账号只能绑定一个 Gryphline 账号，一个 Gryphline 账号信箱也只能绑定一个 PSN 账号 |

- 绑定后，PlayStation 5 仍只能用 PSN 账号登录，PC 与行动装置仍只能用 Gryphline 账号登录。
- 在其他平台取得的进度，会在下次登录 PlayStation 5 时解锁对应的奖杯。
- PlayStation 5 上有两个好友列表：「明日方舟：终末地的好友」在任意平台可见，「PlayStation™Network的好友」只在 PlayStation 5 上可见。

## Steam

| 阶段 | 内容 |
| --- | --- |
| 「先锋测试」 | 正式上线前、名额有限的测试，使用线上正式服务器，开放付费且不删档 |
| 正式上线 | 2026-10-15 的 1.6 版更新后，支援两个服务器。「先锋测试」期间的进度与购买都保留 |

- 只以 Google、Apple 或 Facebook 登录过的 Gryphline 账号，要先在 Gryphline 通行证帐户中心绑定信箱，才能与 Steam 连结。
- Steam 账号可在游戏内「设定」→「平台与帐户」→「帐户中心」解除连结，也可在 Gryphline 通行证帐户中心网站解除。

## 更新游戏

1.4 版整合并优化资源，使行动装置客户端变小。

| 平台 | 更新方式 |
| --- | --- |
| PC，GRYPHLINK | 关闭游戏，重新启动 GRYPHLINK 并点击更新 |
| PC，Steam | 在 Steam 收藏库下载新版本 |
| Android | 依照游戏内弹出视窗提示 |
| iOS | 在 App Store 点击更新 |
| PlayStation 5 | 在系统界面选择游戏，按「选项（OPTIONS）」按钮，再选「检查更新」 |

## NVIDIA 显示卡的已知问题

| 起始 | 问题 | 解决方式 |
| --- | --- | --- |
| 2026-02-07 | NVIDIA App 的优化功能可能导致画面模糊与卡顿 | 在 NVIDIA App 的图形 → 程式设定中选择游戏并恢复为未优化，关闭新游戏的自动优化；或在游戏内调低 DLSS 模式或画质 |
| 2026-03-17 | GeForce Game Ready 驱动程式 595.79、595.71 与 NVIDIA Studio 驱动程式 595.79 可能导致卡顿 | 在 GRYPHLINK 勾选 DirectX 11 启动，或在 NVIDIA App 重新安装旧版驱动程式 |

## 启动器与辅助工具

- GRYPHLINK 启动器有游戏即时数据面板（2026-07-10 新增）：以 Gryphline 账号登录后，点击「查看角色看板」可在游戏离线时查看理智、日常活跃度与每周事务，并在账号下的角色之间切换。
- 游戏工具从游戏内的「协议同步器」进入，提供 WIKI、地图工具、「协议终端」与阵容分享。

《明日方舟：终末地》的伤害分为物理伤害、法术伤害与超域伤害，法术伤害又分灼热、电磁、寒冷、自然。法术攻击会在敌人身上留下法术附着，同属性最多 4 层：再叠加同属性的附着会触发法术爆发，遇上其他属性的附着则触发法术异常（燃烧、导电、冻结或腐蚀）。物理异常第一次命中只会让敌人破防；之后击飞与倒地叠加破防层数，猛击与碎甲消耗层数。失衡值累积满时敌人进入失衡状态，可以被处决。伤害是多个乘区相乘的结果：基础伤害（多数依攻击力计算）、暴击、伤害加成、目标的防御力与抗性，以及失衡状态。NGA 论坛玩家在 1.0 版实测：防御乘区为 100 / (防御力 + 100)，敌人常见的基础防御力 100 时为 0.5；失衡状态的敌人受到 ×1.3 伤害。

## 伤害公式

以下公式为 NGA 论坛玩家 666bj 在 1.0 版的实测整理。一般伤害指物理异常、法术异常与法术爆发以外的所有伤害，等于下列乘区相乘：

| 乘区 | 数值 | 多个效果如何叠加 |
| --- | --- | --- |
| 基础伤害 | 伤害倍率 × 效果所依据的属性（通常是攻击力），再加上基础伤害提升值 | |
| 暴击 | 暴击时为 1 + 暴击伤害，否则为 1；平均为 1 + 暴击率 × 暴击伤害 | |
| 伤害加成 | 1 + 所有伤害加成之和：伤害类型、技能类型、对失衡目标的伤害与其他 | 相加 |
| 伤害减免 | 各项 (1 − 减免) 相乘 | 相乘 |
| 增幅 | 1 + 增幅效果之和 | 相加 |
| 虚弱 | 各项 (1 − 虚弱) 相乘 | 相乘 |
| 庇护 | 1 − 最强的庇护 | 只取最高值 |
| 脆弱 | 1 + 脆弱效果之和 | 相加 |
| 其他受到伤害提高 | 1 + 未标为脆弱、但提高受到伤害的效果之和，例如导电提高的法术伤害、碎甲提高的物理伤害 | 相加 |
| 防御 | 有效防御力为 0 或以上时为 100 / (防御力 + 100)；无视防御力的伤害为 1 | |
| 失衡 | 敌人处于失衡状态时为 1.3，否则为 1 | |
| 抗性 | 1 − 抗性 / 100 + 无视的抗性 / 100 | |
| 非主控 | 1；部分强大敌人的攻击打在非主控干员身上时为 0 至 0.7 | |
| 连击 | 1 至 4 层连击时，战技 +30%、+45%、+60% 或 +75%，终结技 +20%、+30%、+40% 或 +50% | 可以叠加，效果递减 |
| 特殊 | 独立于以上乘区的其他效果 | 相乘 |

- 攻击力 = [(干员基础攻击力 + 武器基础攻击力) × (1 + 攻击力百分比加成) + 攻击力固定数值加成] × (1 + 能力值加成)。能力值带来的能力值加成 = 主能力 × 0.005 + 副能力 × 0.002，能力值只计整数部分；部分干员的天赋会另外提供能力值加成。
- 干员的基础暴击率为 5%，基础暴击伤害为 50%。敌人的暴击率为 0%，暴击伤害为 50%。
- 所有技能伤害加成作用于战技、连携技与终结技，不包括普通攻击。处决可以受益于普通攻击伤害加成。
- 敌人的基础防御力在任何等级都是 100，所以没有改变防御力的效果时，受防御力影响的伤害防御乘区为 0.5。干员的基础防御力为 0，防御力一般来自装备的主属性。
- 每 1 点抗性使该类伤害降低 1%。游戏内以等级显示敌人的抗性：0 为 D，20 至 40 为 C，50 与 60 为 B。敌人的抗性多为 0 或 20；少数敌人在某一属性上有 30、35、40、50 或 60，没有敌人具有超域抗性。每种敌人的数值见[敌人抗性](/zh-cn/systems/enemies/)。
- 干员的物理抗性 = 100 − 100 / (0.001 × 敏捷 + 1)，法术抗性以智识同样计算，敏捷与智识只计整数部分。干员的抗性乘区最低为 0.1。
- 游戏中许多数值显示时无条件舍去小数，所以用显示的数值计算，结果可能差几点。

干员触发的物理异常、法术异常与法术爆发，伤害使用上述乘区，但没有非主控与连击，另外多两个乘区：

| 乘区 | 数值 |
| --- | --- |
| 等级 | 法术异常与法术爆发：1 + (触发干员的等级 − 1) / 196，90 级时为 1.454。物理异常：1 + (等级 − 1) / 392，90 级时为 1.227 |
| 源石技艺强度 | 1 + 源石技艺强度 / 100 |

| 伤害 | 伤害倍率（攻击力的百分比） |
| --- | --- |
| 燃烧、导电、冻结、腐蚀：初始伤害 | 80% × (1 + 异常等级) |
| 燃烧：每秒的持续伤害 | 12% × (1 + 异常等级) |
| 碎冰（物理伤害，计算等级乘区时视为法术异常） | 120% × (1 + 异常等级) |
| 任何法术爆发 | 160% |
| 击飞、倒地 | 120%，并累积 10 点失衡值 |
| 碎甲 | 50% × (1 + 异常等级) |
| 猛击 | 150% × (1 + 异常等级) |

| 异常等级 1 / 2 / 3 / 4 的效果 | 数值 |
| --- | --- |
| 导电：敌人受到的法术伤害提高 | +12% / 16% / 20% / 24%，持续 12 / 18 / 24 / 30 秒 |
| 碎甲：敌人受到的物理伤害提高 | +12% / 16% / 20% / 24%，持续 12 / 18 / 24 / 30 秒 |
| 腐蚀：所有抗性降低 | 立即降低 3.6 / 4.8 / 6 / 7.2，之后每秒降低 0.84 / 1.12 / 1.4 / 1.68，最多降低 12 / 16 / 20 / 24；初始持续 15 秒；刷新腐蚀会维持已累积的抗性下降 |
| 燃烧 | 10 秒 |
| 冻结 | 6 / 7 / 8 / 9 秒 |

- 源石技艺强度也会强化碎甲、导电与腐蚀的附带效果：效果乘以 1 + 2 × 源石技艺强度 / (源石技艺强度 + 300)。把这类附带效果提升为原本若干倍的效果（例如潜能的 ×1.33），在此之后再相乘。对击飞与倒地，每点源石技艺强度使累积的失衡值 +0.5%。
- 技能直接施加、未消耗法术附着的法术异常，默认没有初始伤害。

| 物理 | 物理 | 9 |

游戏数据 1.6 的 34 名干员，属性都是物理或四种法术属性之一，没有干员的属性是超域。各属性的干员列于下方依属性分的干员表。

## 法术附着、法术爆发与法术异常

| 用语 | 说明 |
| --- | --- |
| 法术附着 | 附着在敌人身上的法术标记，分四种属性。同属性最多叠加 4 层。 |
| 法术爆发 | 对已有某属性附着的敌人再施加同属性附着时触发，造成该属性伤害。 |
| 法术异常 | 同一名敌人身上有两种不同属性的附着时触发的法术减益，会消耗附着。游戏把每一种写成其他法术附着加上某属性附着，例如燃烧 = 其他法术附着 + 灼热附着。 |
| 异常等级 | 触发法术异常或物理异常时消耗的附着层数（或破防层数），最高 4 级。等级越高效果越强。 |

| 属性 | 法术爆发 | 法术异常（该属性附着加上其他属性附着） | 对敌人的效果 | 干员被叠满 4 层时 |
| --- | --- | --- | --- | --- |
| 灼热 | 灼热爆发：灼热伤害 | 燃烧 | 持续受到灼热伤害 | 燃烧：持续受到无视防御力的灼热伤害 |
| 电磁 | 电磁爆发：电磁伤害 | 导电 | 受到的法术伤害提高 | 导电：短暂晕眩，且一段时间内受到的法术伤害提高 |
| 寒冷 | 寒冷爆发：寒冷伤害 | 冻结 | 无法行动；此时受到破防或物理异常会触发碎冰 | 冻结：一段时间内无法行动 |
| 自然 | 自然爆发：自然伤害 | 腐蚀 | 所有抗性逐渐下降 | 腐蚀：一段时间内无法冲刺，移动速度降低 |

敌人的技能也会对干员叠加法术附着；最后一栏是同属性叠满 4 层时干员受到的效果。

## 物理异常与破防

敌人第一次受到物理异常时，不会触发异常效果，而是进入破防状态。破防最多叠加 4 层。

| 物理异常 | 对已破防的敌人 |
| --- | --- |
| 击飞 | 叠加 1 层破防，造成物理伤害并累积失衡值 |
| 倒地 | 叠加 1 层破防，造成物理伤害并累积失衡值（与击飞规则相同） |
| 猛击 | 消耗所有破防层数，造成大量物理伤害 |
| 碎甲 | 消耗所有破防层数，造成物理伤害，并使敌人一段时间内受到的物理伤害提高 |
| 碎冰 | 不是独立的异常：对冻结中的敌人施加破防或任何物理异常时，消耗冻结并造成大量物理伤害 |

猛击与碎甲也有异常等级，和法术异常一样，等于消耗的破防层数。

## 失衡、处决与重击

| 用语 | 说明 |
| --- | --- |
| 失衡值 | 大部分技能与主控干员的重击命中时累积。累积满时敌人进入失衡状态。 |
| 失衡状态 | 一段时间内敌人无法行动，受到的伤害增加。很快就进入失衡的敌人，在第一次失衡结束后的一段时间内，累积的失衡值会降低。 |
| 失衡节点 | 部分强大敌人的失衡条上的节点。累积到节点时会打断敌人并使其踉跄。 |
| 处决 | 对失衡状态的敌人第一次普通攻击：造成大量伤害并回复一定技力。 |
| 重击 | 普通攻击的最后一段。主控干员的重击会累积失衡值并回复技力。 |

## 技力、技能与终结技能量

| 技能 | 消耗 | 冷却 | 游戏数据 1.6 的数值 |
| --- | --- | --- | --- |
| 普通攻击 | 无 | 无 | 非主控的队友会自动普通攻击 |
| 战技 | 技力 | 无 | 34 名干员中 33 名消耗 100 点技力；[梨诺](/zh-cn/operators/liino/) 消耗 25 点 |
| 连携技 | 无 | 有 | 达成该干员自己的触发条件才能施放；技能等级 1 时冷却 3 至 40 秒 |
| 终结技 | 全部终结技能量 | 施放后短暂冷却 | 能量需充满：依干员为 70 至 300 点；冷却 10、15、20 或 30 秒 |

- 技力用来施放战技，会随时间自动回复；主控干员的重击与处决也会回复技力。
- 终结技能量来自施放战技（全队获得等量）与施放连携技（只有施放者获得）。终结技会让自己进入强化状态的干员，在强化期间不会获得终结技能量。
- 一支小队最多 4 名干员。每名队员的战技、连携技与终结技都要手动施放。

## 增益、减益与其他用语

| 用语 | 效果 | 同类效果 |
| --- | --- | --- |
| 增幅 | 一段时间内目标造成的某种属性伤害提高（物理增幅、灼热增幅、法术增幅等） | 可以叠加 |
| 脆弱 | 一段时间内目标受到的某种属性伤害提高 | 可以叠加 |
| 庇护 | 一段时间内目标受到的伤害降低 | 只取最高值 |
| 虚弱 | 一段时间内目标造成的伤害降低 | 以非线性方式叠加 |
| 护盾 | 持续期间吸收伤害；部分护盾只吸收特定类型的伤害 | |
| 缓速 | 一段时间内移动速度降低 | 只取最高值 |
| 加速 | 一段时间内移动速度提高 | 可叠加至上限 |
| 定身 | 持续期间目标暂停行动 | |
| 净化 | 清除干员身上的特定异常状态 | |
| 连击 | 全队下一次战技或终结技伤害提高，战技提高较多；触发后清空 | 可以叠加，效果递减 |
| 返还技力 | 消耗技力后达成条件时，取回一部分技力。不算回复技力：不触发回复技力时的效果，消耗这部分技力也不会获得终结技能量 | |
| 状态消耗 | 状态因其他效果而提前结束：猛击消耗破防，法术异常消耗法术附着 | |
| 吸收 | 状态以特殊方式提前结束；不算消耗 | |
| 持续伤害 | 随时间造成的伤害；无法暴击 | |
| 固定伤害 | 无视防御与抗性，也不受任何伤害提高或降低效果影响 | |

只属於单一干员的状态：

| 状态 | 干员 | 效果 |
| --- | --- | --- |
| 源石结晶 | [管理员](/zh-cn/operators/endministrator/) | 连携技让敌人附着结晶，使其无法行动 |
| 爪印斫痕 | [洛茜](/zh-cn/operators/rossi/) | 战技施加：持续受到物理伤害，且受到的物理与灼热伤害增加 |
| 启示 | [提弗洛斯](/zh-cn/operators/typhoeus/) | 消耗敌人的自然附着或敌人受到自然爆发时累积；连携技把启示转换为猎矢 |
| 猎矢 | [提弗洛斯](/zh-cn/operators/typhoeus/) | 浮空时消耗，强化射击，伤害更高并额外触发自然爆发 |

1.4 版「向渊行」是公测后的第四次更新，属于核心章节版本，更新维护于 2026-07-16 06:00 至 12:00 进行。从这个版本起，管理员完成「第一章 - 进度II - 修缮进展」后即可接取武陵的第二章主线任务，不必先完成第一章。

## 新增内容

| 类别 | 新增 |
| --- | --- |
| 主线任务 | 开放至「第二章 - 进度VII - 余晖未却」 |
| 区域 | 武陵 - 应龙关、武陵 - 北部禁区 |
| 干员 | [诀](/zh-cn/operators/arcane/)与[梨诺](/zh-cn/operators/liino/)，皆为 6 星 |
| 6 星武器 | 四二式·肃阵（施术单元）、曜夜的首演（长柄武器）、遥望（单手剑）、联结点（施术单元）、黄金时代（长柄武器） |
| 敌人 | 「阿莱克琉斯，千夫长」与 8 种蚀影敌人，其中有蚀影应龙队长 |
| 集成工业 | 武陵的气体工业（气体收集、气体反应炉等工业规划）、气体「惰气」与「息壤气」、据点「盈天台建设站」 |
| 装备套装 | 集成实训、涉渊 |
| 材料 | 塔罗斯菌（晋升）、红矛叶（技能专精）、协议纹石（武器突破） |

## 系统变更

- 提前前往武陵：武陵大部分敌人的等级随探索等级变化；在武陵摆放协议核心后会先解锁一批集成工业设备，这些设备要在完成对应工业技术研究后才能在四号谷地使用。
- 战斗：可设定队友技能特效的品质与不透明度；索敌分为三项独立设定（技能优先攻击目标、主动锁定目标、辅助选择目标）。
- 新功能：塔晶集换（在应龙关与北部禁区收集塔晶）、材料转化（在简易制作中把高等级材料转为低等级材料）、生日、ID信息更新卡（每半年免费一张）、查看已拥有干员的 2D 立绘。
- 干员试用活动的奖励新增武库防具箱，内含适合该试用干员的满精锻 60 级套装装备。
- 集成工业：「武陵」地区建设等级上限提升；暗管连接距离改以直线计算，上限由 200 m 提高到 300 m；协议核心区域以外的设备可从地图直接收回；金色品质装备可切换制造工艺，使用最新工艺时调度券消耗减少 99%。
- 装饰物品不再占用背包与仓库容量。寻访纪录与申领纪录保留 90 日内的特许寻访与武库申领奖励纪录。
- O.M.V.帝江号：会客室线索交流由 24 小时缩短为 20 小时，舱室可从总控中枢远端升级。
- 画面：PC 支援 NVIDIA DLSS 4.5 超解析度与 AMD FSR 3，PlayStation 5 Pro 支援升级版 PSSR。
- 修复：[阿列什](/zh-cn/operators/alesh/)解锁潜能「咸鳞翻身」后，施放战技无法触发部分武器技能效果。
- 修复：[昼雪](/zh-cn/operators/snowshine/)为主控干员时，特定操作后画面异常转动；[卡契尔](/zh-cn/operators/catcher/)在队伍中施放重击时画面抖动；行动装置上[庄方宜](/zh-cn/operators/zhuang-fangyi/)的下坠攻击没有震动回馈；卡缪的翅膀在界面转场时显示异常。
- 弭弗的连携技音效经过优化。

1.1 版「新潮起，故渊离」是[公测](/zh-cn/versions/1-0/)后的第一次更新，更新维护于 2026-03-12 06:00 至 12:00 进行。这个版本开放了武陵的新区域清波寨。

## 新增内容

| 类别 | 新增 |
| --- | --- |
| 主线任务 | 开放至「第二章 - 进度III - 共饮一江水」 |
| 探索任务 | 「据点建设·天王坪援助点·二」、「侵蚀中的呼救」 |
| 支线任务 | 「夺宝奇兵·其一」至「夺宝奇兵·其三」、「泉中客·其一」至「泉中客·其三」、「红骑士」 |
| 区域 | 武陵 - 清波寨 |
| 干员 | [汤汤](/zh-cn/operators/tangtang/)与[洛茜](/zh-cn/operators/rossi/)，皆为 6 星 |
| 6 星武器 | 落草（手铳）、望乡（手铳）、狼之绯（单手剑）、光荣记忆（单手剑） |
| 敌人 | 莫惜命、过堂风、劫云客、割云翁、断云叟、摧山将、开天将等 |
| 集成工业计划 | 武陵工业二期：洪炉扩容II、水辅矿物采掘、暗管、废水处理、液辅熔炼、AF1「熔甲者」、激流塔 |
| 集成工业设备 | 水驱矿机、暗管入口、暗管出口、AF1「熔甲者」、激流塔；矿点赤铜矿 |
| 新手任务 | 「新手特许赠礼」，常驻，可得特许寻访凭证 ×10 |

## 系统变更

- 集成工业：可在地图上任意位置消耗携带的材料制造设备，无需返回集成核心区域。
- 集成工业：可在地图界面直接删除他人留下的共享设备，共享滑索与自建滑索的样式有所区分；登上滑索架、开始滑动前显示小地图。
- 集成工业：电线保持不断开的距离延长，中继器由 90m 提升至 100m，供电桩由 40m 提升至 50m；电路连接距离不变。
- 集成工业：俯瞰模式的可见范围扩大；PC 版可设定按 ESC 键关闭俯瞰模式，并可长按滑鼠左键移动多个已选取的设备；控制器模式新增「移动」选项。
- 地区建设：「武陵」地区建设等级上限，以及物资调度、仓储节点、环境监测与「天王坪援助点」据点的等级上限提升。「四号谷地 - 矿脉源区」的物资调度升至 4 级后，谷地多痕刻写箱可得一个包含三条自定义属性的基质。
- 挑战干员养成、武器养成、危境再现与危境预演相关的协议空间时，小队以独立的满生命值、满终结技能量状态进入战斗，与外部状态互不影响。
- 未及时拾取的稀有植物、稀有矿物与部分协议空间的材料，会自动送往信箱暂存区。
- 十个装备套装新增部分装备部件，包括 50式应龙装备组、点剑装备组与纾难装备组。所有干员新增切换时的语音与受击时的表情反应。
- 设定：「控制」新增镜头距离，「效能与画面」新增显示模式。
- 伊冯终结技的描述改写，实际效果不变。[安塔尔](/zh-cn/operators/antal/)的中文配音演员姓名更新。4 星武器「紧急手段」更名为「显锋」。
- 莱万汀的修复：强化战技的追加攻击瞬间冲刺，或以该追加攻击击败处于灼热附着状态的敌人时，熔火层数异常；终结技即将结束时施放战技，终结技提前结束。
- 其他干员的修复：伊冯无法处决敌人；别礼的连携技无法凝结敌人；余烬施放战技期间受到多段攻击时表现异常，第三段普通攻击会失去目标；[大潘](/zh-cn/operators/da-pan/)的终结技与连携技失去目标；[艾维文娜](/zh-cn/operators/avywenna/)的潜能「恩威并施」改为与描述一致，「筹码加倍」不再异常生效。
- 平台：这个版本期间起可在 NVIDIA GeForce NOW 游玩，同一服务器内进度与其他平台互通。

1.2 版「春晓时」是公测后的第二次更新，属于核心章节版本，更新维护于 2026-04-17 06:00 至 12:00 进行。

## 新增内容

| 类别 | 新增 |
| --- | --- |
| 主线任务 | 开放至「第二章 - 进度VI - 志同道合」 |
| 支线任务 | 同袍（四部）、重逢故人、老人与潮、街角的商店、再引春来 |
| 探索任务 | 据点建设·心脏修缮站·一与二、净水节点、粉丝见面会、致后来人、分忧解难 |
| 区域 | 「武陵 - 首墩」、「武陵 - 试验园区」；「武陵 - 武陵城」的技术开发局与弃剑台 |
| 干员 | [庄方宜](/zh-cn/operators/zhuang-fangyi/)，6 星 |
| 6 星武器 | 孤舟（施术单元）、雾中微光（施术单元） |
| 敌人 | 天鼓、表象、聂菲斯「碾骨」、聂菲斯「征服者」 |
| 集成工业 | 「武陵工业三期」与八种设备，包括提纯机、扩容反应池、高能射线塔；液体采集物沉积酸；据点心脏修缮站 |
| 装备套装 | 壤流、清波 |
| 新手活动 | 「干员培养助力」，常驻：达成培养目标返还培养材料 |

1.2 版只有一期特许寻访。「春雷动，万物生」是汤汤的第三期特许寻访，因此下一期特许寻访（[1.3 版](/zh-cn/versions/1-3/)）的名单已没有汤汤。

「辉光庆典」采用专属规则，寻访次数与保底计数不与任何其他寻访互通。在其中每次寻访（含加急招募）可额外获得保障配额 ×1。累计 30 次获得加急招募（1 次免费十连），累计 60 次获得基础寻访凭证 ×10（仅 1 次），累计 120 次获得流光庆时调用凭证 ×1（仅 1 次，可从名单的四名 6 星干员中免费选一名），每累计 240 次获得流光庆时信物补给 ×1（四人之一的信物，限已拥有的干员）。另见[寻访概率与保底](/zh-cn/systems/headhunting/)与[武库申领与基质](/zh-cn/systems/arsenal/)。

## 系统变更

- 月卡：自这个版本起，每日奖励追加理智消耗许可 ×4。
- 理智消耗许可：「地区建设 - 物资调度」追加可购买的数量。
- 战斗：持续一段时间的终结技在画面下方显示剩余时间；在危境再现挑战领袖敌人时显示战斗计时。
- 帝江号：「总控中枢」新增总控事项，可一次收取产物、安排生产并领取与填入线索。
- 4 级资源回收站可从地图一次远端收取该地区所有 4 级资源回收站的资源。
- 装备：「干员 - 装备」界面新增装备制造按钮，并可一次制作多件装备。
- 寻访与武库申领：嵌晶玉或武库配额不足时，可选择当日免提示自动消耗衍质源石；简化寻访跳过动画的流程。
- 集成工业：「武陵」地区建设等级上限提升；仓储节点的运送委托可依地区筛选；在集成核心区域移动暗管出入口不再断开连接。
- 与「埃尔埃格尼斯」的剧情战斗，进入战斗一段时间后可跳过。
- 操作与画面：控制器按钮可自定义；部分 Android 装置支援画格生成；部分 iOS 装置的总桩办公室场景支援光线追踪。
- 莱万汀终结技的描述补充：施放战技焚灭或连携技沸腾期间，终结技黄昏的持续时间不会减少；实际效果不变。连携技的技能详情会说明是否获得终结技能量。
- 修复：洁尔佩塔、[阿列什](/zh-cn/operators/alesh/)、[萤石](/zh-cn/operators/fluorite/)的处决伤害在特定情况下无法获得部分加成；汤汤终结技的状态图示时间与实际效果不同步；别礼的连携技可能提前打断汤汤的终结技；[狼卫](/zh-cn/operators/wulfgard/)作为非主控干员普通攻击时画面异常震动；洛茜在编队界面的武器模型显示异常。

1.6 版「丹青渡」是公测后的第六次更新，也是游戏登陆 Steam 的版本。更新维护于 2026-10-15 06:00 至 12:00 进行。

## 新增内容

| 类别 | 新增 |
| --- | --- |
| 主线任务 | 开放至「第二章 - 进度VIII - 着新墨」 |
| 探索任务 | 奇闻满地跑、后目的地、开画大吉、农植自动化改造 |
| 支线任务 | 归野、无终之恋、前缘再续、纪念日、缘缘庄经营·其一至其三 |
| 区域 | 武陵 - 祀的画 |
| 干员 | [祀](/zh-cn/operators/si/)与[明河](/zh-cn/operators/argent-flow/)，皆为 6 星 |
| 6 星武器 | 玉中身（双手剑）、唤月（单手剑）、悠久传承（双手剑）、聚合工业（单手剑） |
| 敌人 | 存禄、用奇、解燥、行度等 |
| 集成工业设备 | 自动农植机，用于「祀的画」的种植区，之后也可用于「武陵城」的种植区 |
| 玩法 | 缘缘庄客栈，没有经营任务 |

## 系统变更

- 战斗：可在编队界面设定连携技的优先顺序，并新增第六、第七小队。
- 装备方案：可保存多套装备配置、自定义命名并切换。
- 有时效的理智药剂到期时自动转化为理智；超出理智上限的部分，在有理智萃取器时转化为理智精粹药剂，否则销毁。
- 舱室小组：每个舱室可设定 A、B 两个班组，手动启用或自动轮换。
- 集成工业：「武陵」地区建设等级上限提升；设备可直接从背包或任意仓库摆放。
- 汤汤终结技的描述改写为施加定身，实际效果不变。
- 平台：新增 Steam 客户端，账号与服务器相同。
